## A3.2 Centroids, Center of Gravity.

線分、面積、体積、または質量の重心とは、その線分、面積、体積、または質量全体が集中しているとみなされ、かつ真の分布状態にある場合と同様に軸に対する同じモーメントを持つと想定される点である。この一般的な関係は、モーメントの原理によって次のように表すことができる：

$$
\begin{align*}
\text{Lines:- } \bar{x}L = \sum Lx, \text{ hence } \bar{x} = \frac{\sum Lx}{L} = \frac{\int xdL}{L}\\
\text{Areas:- } \bar{x}A = \sum ax, \text{ hence } \bar{x} = \frac{\sum ax}{A} = \frac{\int xdA}{A}\\
\text{Volumes:- } \bar{x}V = \sum Vx, \text{ hence } \bar{x} = \frac{\sum Vx}{V} =\frac{\int xdV}{V}\\
\text{Masses:- } \bar{x}M = \sum xm, \text{ hence } \bar{x} = \frac{\sum mx}{M} = \frac{\int xdM}{M}
\end{align*} 
$$



ある図形が直線または平面に対して対称である場合、その図形の重心は与えられた直線または平面上に位置する。これは、図形の直線または平面の反対側にある部分のモーメントが数値的には等しいが符号が反対であるという事実から明らかである。図形が二つの直線または平面に対して対称である場合、その図形の重心は二つの直線の交点、または二つの平面の交点に位置する。同様に、図形が三つの対称平面を持つ場合、重心は三つの平面の交点に位置する。
