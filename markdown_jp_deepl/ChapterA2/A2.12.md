### Example Problem 10. Externally Braced Monoplane Wing Structure

図A2.35は、外部ブレース付き単葉翼の構造寸法図を示す。翼は翼梁間に布張りされており、したがって抗力方向の強度と剛性を確保するため、支柱とタイロッドで構成される抗力トラスが必要である。揚力トラスと抗力トラスの全部材における軸方向荷重を決定する。本問題の目的は静定空間トラス構造の解法を学生に練習させることであるため、簡略化された空気荷重を仮定する。

#### ASSUMED AIR LOADING:-

(1) 翼端から支柱点まで45 lb/inの一定な翼幅方向揚力荷重が作用し、その後翼端で22.5 lb/inまで漸減する。

(2) 6 lb/inの前方均一分布抗力荷重。

上記の空気荷重は高迎え角状態を表す。この状態では図A2.36に示すように抗力トラスに前方荷重が作用する。

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-36-2.png)

空気力学における揚力と抗力を抗力トラス方向に投影すると、揚力による前方への投影力は空気抵抗による後方への投影力よりも大きく、この差は例題では6 lb/inと仮定されている。低迎え角では、抗力トラス方向の荷重は後方へ作用する。



#### SOLUTION:

前部および後部ビームにかかる走行荷重は、解法の第一段階として計算される。当飛行条件においては、空気力の圧力中心は図A2.37に示す通りと仮定する。

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-36-3.png)

$45 - 30.26 = 14.74 \text{ lb/in}$ が後梁にかかる荷重となる。

トラスシステムの荷重を節点法で求めるには、すべての荷重をトラスの節点に伝達しなければならない。主翼梁は一端が胴体で支持され、外側では二つのリフトストラットで支持されている。したがって、各梁にかかる走行リフト荷重による、ストラット点とヒンジ点における各梁の反力を計算する。

### Example Problem 11. 3-Section Externally Braced Wing.

図A2.41は高翼で外部ブレースを有する翼構造を示す。翼外パネルは例題1の翼パネルと同一構造としている。この外パネルは中心パネルに対し、点(2)と(4)で単一ピン接合により取り付けられている。これらの位置にピンを設置することで構造は静定となる。一方、3枚のパネル全てを連続した梁とすると、リフトストラットとカバンストラットが翼梁に及ぼす反力は静不定となる。これはストラット変形により沈下支持点に載る3スパン連続梁が生じるためである。点(2)と(4)の接合ピンは梁の中立軸に対して偏心配置可能であるため、横方向の梁曲げモーメント低減を目的とした梁の連続化による利点は極めて小さい。組立・収納・輸送の利便性から、この翼は3分割で製造するのが望ましい。点(2)と(4)に連続梁を得るため複数ボルト継手を使用しても大きな利点は得られない。各政府機関の設計要件では複数ボルト継手が完全連続性の50％しか提供しないという仮定のもとで翼梁を解析することが規定されているためである。

### Example Problem 12. Single Spar Truss Plus Torsional Truss System.


小型の翼や操縦翼面では、表面被覆材として布地がしばしば用いられる。布地は信頼性の高いねじり抵抗を提供できないため、内部構造はねじり強度を確保する設計でなければならない。単一主桁と特殊なトラスシステムを組み合わせた構造が、満足のいく強度を得るために頻繁に採用される。図A2.46は、このような構造、すなわちトラス式単一主桁AEFNと、主桁と後縁OS間の三角トラスシステムを示す。図A2.46(a,b,c)は
3つの投影図と寸法を示す。構造体表面被覆にかかる空気荷重は、主桁線上で0.5 lb./in²の強度を持ち、後縁に向かって線形に変化してゼロとなると仮定する（図d参照）。


本課題では構造体全部材の軸方向荷重を決定する。トラス構造における主荷重解析と同様に、全部材を2力部材と仮定する。

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-41-1.png)


#### SOLUTION:

構造物にかかる空気荷重の総量は、
平方インチあたりの平均強度と表面積の積、
すなわち $(0.5)(0.5)(36 \times 84) = 756 \text{ lb}$ となる。
トラスシステムを節点法で解くには、分散荷重を構造物の節点に作用する等価な荷重システムに置き換える必要がある。図(d)を参照すると、幅1インチ・長さ36インチの帯状部材にかかる総空気荷重は $36(0.5)/2 = 9 \text{ lb}$ であり、その重心（合力点）は線AEから12インチの位置にある。図A2.46aでは、この9 lb/inの合力荷重が仮想ビーム（線1-1に沿って配置）に作用すると仮定する。この線に沿って作用する連続荷重は、接合部OPQRSEDBCAに作用する等価力系に置き換えられる。この接合部分配の結果は、図A2.46の接合部荷重で示される。これらの関節荷重がどのように得られたかを説明するため、関節ESDRにおける荷重の計算を示す。

図A2.48は検討対象構造物の一部を示す。線1-1に沿った9 lb./in.の走行荷重に対し、点2、3、4、5などに支えられた単純梁としての反力が生じる。2-3間の距離は8インチである。この距離にかかる総荷重は $8 \times 9 = 72 \text{ lb}$ である。その半分である36 lbは点(2)に、残りの半分は点(3)にかかる。点(2)の36ポンドは、点Eに等価な力系で置き換えられる。点Sには8ポンド（36/3=12ポンド）、点Eには24ポンド（36×(2/3)=24）が作用する。点(3)と(4)間の距離は8インチであり、荷重は $8 \times 9 = 72 \text{ lb}$ となる。
この半分の36 lbが点(3)に作用し、これに先の36 lbを加えると点(3)で72 lbとなる。この72の荷重は、砂丘Dにおいて等価な力系で置き換えられる。すなわち、(72)/3 = 24 lb. が8に、(72)(2/3) = 48 lb. がDにかかる。したがって、Sにおける最終的な荷重は図に示す通り $24 + 12 = 36 \text{ lb}$ となる。A 2.46. 三角形CRDの対称性により、距離CD上の総荷重の半分は点(4)と(5)に作用する。すなわち $(24 \times 9)/2 = 108\text{ lb}$ 。したがってDへの分布は $(108)(2/3) = 72$  、Rへの分布は $(108)/3 = 36$ となる。Dの既存荷重48に72を加えると、図A2.46に示す通りDの総荷重は120 lbとなる。点(5)の108 lbからも、Rへの配分量は $(108)/3 = 36$ となり、Rの総荷重は72 lbとなる。学生は図A2.46に示す通り、他の接合部への配分量を確認すべきである。



導出された接合部荷重システムと元の空気荷重システムの等価性を確認するには、各システムの大きさとモーメントが同一でなければならない。図A2.46に示すように接合部荷重の合計を計算すると756 lbとなり、元の空気荷重と一致する。

線分AEを軸とする空気負荷全体のモーメントは
$756 × 12 = 9072 in.lb.$ である。
分散された接合部荷重のモーメントは
$(6 + 66 + 72 + 72 + 36)36 = 9072$ または確認。


##### Calculation of Reactions



構造は点A、N、0における単一ピン継手で支持され、ピン軸はx軸と平行である。N点における継手はZ方向のスパー荷重を支持すると仮定する。図A2.46は反力 $O_y, O_z, A_y, N_y, N_z$ を示す。$O_z$ を求めるには、スパーAEFNに沿ってy軸周りのモーメントを計算する。


$$
\begin{align*}
\sum M_y = (6 + 66 + 72 + 72 + 36)36 - 36 O_z = 0\\
\text{whence } O_z = 252 \text{ lb. acting down as assumed.}\\
\text{To find } O_y \text{ take moments about z axis through point (A).}\\
\sum M_z = 0 + 36 O_y = 0, Oy = 0
\end{align*} 
$$

$A_y$を求めるには、点Nを通るx軸に対するモーメントを求める。
空気荷重のモーメントは以前に-31752と計算済みであるため、

$$
\begin{align*}
\sum M_x = - 31752 + 9 A_y = 0, \text{ whence, } A_y = 3528 \text{ lb.}\\
\text{To find } N_y \text{ take } \sum F_y = 0\\
\sum F_y = 3528 - N_y = 0, \text{ hence } N_y = 3528 \text{ lb.}\\
\text{To find } N_z \text{ take } \sum F_z = 0\\
\sum F_z = -252 + 756 - N_z = 0, \text{ hence }N_z = 504 \text{ lb.}
\end{align*} 
$$

The reactions are all recorded on Fig.
A2.46.
