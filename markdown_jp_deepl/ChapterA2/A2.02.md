
## A2.2 Equations of Static Equilibrium.

力を完全に定義するには、
その大きさと方向、作用点を把握しなければならない。
これらは一般に力の特性と呼ばれる。
作用点という呼称の代わりに、
より一般的な作用線または位置という用語が
力の特性として用いられる場合がある。

空間に作用する力は、三方向の分力と三軸周りのモーメントが分かれば完全に定義される。例えば $F_x$、$F_y$、$F_z$ および $M_x$、$M_y$、$M_z$ である。平衡状態または力系においては合力が存在し得ないため、平衡方程式は分力とモーメント成分をゼロに等しくすることで得られる。様々なタイプの力系に対する
静的平衡の方程式を以下にまとめる。


### EQUILIBRIUM EQUATIONS FOR GENERAL SPACE (NON-COPLANAR) FORCE SYSTEM

$$
\begin{equation}
\begin{alignedat}{2}
&\sum F_x = 0               &\sum M_1 = 0\\
&\sum F_y = 0 \text{~~~~} &\sum M_2 = 0\\
&\sum F_z = 0               &\sum M_3 = 0\\
\end{alignedat} 
\tag{2.1}
\end{equation}
$$


したがって、一般的な空間力システムにおいては、
静的平衡の方程式が6つ存在する。このうち3つまでが力の方程式となり得る。
モーメント軸1、2、3を任意のx、y、z軸の組として扱う方が
しばしば便利である。6つの方程式全てを
6つの異なる軸に関するモーメント方程式とすることも可能だ。
力の方程式は3つの互いに垂直な軸に対して記述され、
必ずしもx、y、z軸である必要はない。


### EQUILIBRIUM OF SPACE CONCURRENT-FORCE SYSTEM

同時とは、力系のすべての力が共通点を通ることを意味する。したがって、合力が存在する場合、それはモーメントではなく力であり、合力がゼロでなければならないという条件を完全に定義するには3つの式のみが必要となる。利用可能な平衡式は次の通りである：

$$
\begin{equation}
\begin{alignedat}{3}
&\sum F_x = 0 &&              &\sum M_1 = 0\\
&\sum F_y = 0 &&\text{~~or~~} &\sum M_2 = 0\\
&\sum F_z = 0 &&              &\sum M_3 = 0\\
\end{alignedat} 
\tag{2.2}
\end{equation}
$$

力とモーメントの方程式を組み合わせて
合計3つまで使用できる。
モーメントの方程式においては、
共点を通る軸は使用できない。
なぜなら、系のすべての力が
この点を通るからである。
モーメント軸は、力の方程式で使用される
方向と同じ方向である必要はないが、
もちろん同じ方向でもよい。


### EQUILIBRIUM OF SPACE PARALLEL-FORCE SYSTEM

平行力系においては、すべての力の方向は既知であるが、各力の大きさと位置は未知である。したがって、大きさを決定するには1つの方程式が必要であり、位置を決定するには力が1つの平面に限定されないため2つの方程式が必要となる。一般に、この種の力系において合力をゼロにするために一般的に用いられる3つの方程式は、1つのはり方程式と2つのモーメント方程式である。
例えば、y 方向に作用する空間平行力系の場合、
平衡方程式は次のようになる：

$$
\begin{equation}
\begin{split}
\sum F_y = 0\\
\sum M_x = 0\\
\sum M_z = 0 \\
\end{split}
\tag{2.3}
\end{equation}
$$


### EQUILIBRIUM OF GENERAL CO-PLANAR FORCE SYSTEM

この種の力系では、すべての力が同一平面上に存在し、
そのような力系の合力の大きさと方向、位置を決定するには
3つの方程式のみが必要である。
力の方程式またはモーメントの方程式のいずれかを使用できるが、
使用できる力の方程式は最大2つまでである。
例えば、xy平面内で作用する力系に対しては、
以下の平衡方程式の組み合わせを使用できる。


$$
\begin{equation}
\begin{alignedat}{7}
&\sum F_x = 0 &&              &&\sum F_x = 0    &&              &&\sum F_y = 0    &&              &\sum M_{z1} = 0\\
&\sum M_y = 0 &&\text{~~or~~} &&\sum M_{z1} = 0 &&\text{~~or~~} &&\sum M_{z1} = 0 &&\text{~~or~~} &\sum M_{z2} = 0\\
&\sum M_z = 0 &&              &&\sum M_{z2} = 0 &&              &&\sum M_{z2} = 0 &&              &\sum M_{z3} = 0\\
\end{alignedat} 
\tag{2.4}
\end{equation}
$$

（添字1、2、3はz軸またはモーメント中心の異なる位置を指す。）





### EQUILIBRIUM OF COPLANAR-CONCURRENT-FORCE SYSTEM

すべての力が同一平面上にあり、かつ共通点を通るため、
この種の力系の合力の大きさと方向は未知であるが、
その位置は既知である。なぜなら、交点が合力の作用線上にあるからである。
したがって、合力を定義し、それをゼロにするには、
平衡方程式が二つあれば十分である。
可能な組み合わせは次の通りである：

$$
\begin{equation}
\begin{alignedat}{7}
&\sum F_x = 0 &&\text{~~or~~} &&\sum F_x = 0 &&\text{~~or~~} &&\sum F_y = 0 &&\text{~~or~~} &\sum M_{z1} = 0\\
&\sum F_y = 0 &&              &&\sum M_z = 0 &&              &&\sum M_z = 0 &&              &\sum M_{z2} = 0\\
\end{alignedat} 
\tag{2.5}
\end{equation}
$$

（z軸またはモーメント中心の位置は、
交点を通るものであってはならない）



### EQUILIBRIUM OF CO-PLANAR PARALLEL FORCE SYSTEM

この種の力系では、すべての力の方向が既知であり、かつすべての力が同一平面上に存在するため、このような力系の合力の大きさと位置を定義するには2つの方程式のみで十分である。したがって、この種の力系には、すなわち力とモーメントの方程式、あるいは2つのモーメント方程式という、2つの平衡方程式しか利用できない。例えば、y軸に平行でxy平面上に位置する力の場合、利用可能な平衡方程式は次の通りである： 

$$
\begin{equation}
\begin{alignedat}{3}
&\sum F_y = 0 &&\text{~~or~~} &\sum M_{z1} = 0\\
&\sum M_z = 0 &&              &\sum M_{z2} = 0\\
\end{alignedat} 
\tag{2.6}
\end{equation}
$$

（点中心１と点中心２は同一のy軸上に存在できない）


### EQUILIBRIUM OF COLINEAR FORCE SYSTEM

共線力系とは、すべての力が同一の直線上に作用する系、すなわち力の方向と位置は既知であるが大きさが未知である系を指す。したがって共線力系の合力を定義するには、大きさを求めるだけでよい。ゆえに利用可能な平衡方程式は一つだけであり、すなわち

$$
\begin{equation}
\begin{alignedat}{3}
&\sum F_z = 0 &&\text{~~or~~} &\sum M_{z1} = 0
\end{alignedat} 
\tag{2.7}
\end{equation}
$$
