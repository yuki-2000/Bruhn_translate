## A2.14 Example Problems of Calculating Reactions and Loads on Members of Landing Gear Units


最も単純な形態では、着陸装置は
単一の油圧式ストラットで構成され、
その固定端が支持構造体に剛接された
上端となる片持ち梁として機能する。オーレオストラットの下部シリンダーは、
車輪とタイヤを取り付けるための車軸を
下部に取り付ける。この片持ち梁は、
二方向の曲げ、ねじり、そして軸方向荷重に
さらされる。通常、この装置は格納式に設計されるため、
オレオストラット上端に単一の取り付けユニットを配置し、
この複合荷重に耐えつつ単純な格納機構の動きを可能にする設計は困難である。
さらに、これほど集中した大荷重システムに対して、
翼や胴体構造による貫通支持を提供することも困難である。


したがって、曲げモーメントの大きさと
片持ち支柱の曲げ剛性を低減し、
格納問題と構造上の持ち越し問題を
簡素化するため、通常は油圧支柱に
1本または2本のブレースを追加する。一般的に、
着陸装置構造を静定構造とするため、
部材端部や支持点に特別設計の継手を用い、
作用力の方向と作用点を確立する
努力がなされる。


二つの例題解答を示す。一つは単輪式ギア、
もう一つは二輪式ギアを扱う。


### Example Problem 13

図A2.55はVB面およびVD面における
着陸装置構成の投影図を示す。図A2.56は空間寸法図である。
着陸装置解析では、Z・X・Yの記号に代えて
V・D・Sを基準軸として用いるのが一般的である。
本装置ユニットは三輪式着陸装置システムにおける
主脚片側を想定したものである。
想定される荷重状態は、ノーズホイールが上向き、またはテールが下向きの状態に対応する（図A2.52の下部スケッチ参照）。車輪にかかる設計荷重は垂直方向であり、本問題におけるその大きさは15000ポンドである。

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-47-0.png)

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-47-1.png)


歯車ユニットは支持構造体上の点F、H、Gに固定されている。歯車の後退は、点FとHを通る軸を中心に歯車を後方かつ上方へ回転させることで実現される。点FとHの取付部は曲げモーメントに抵抗するよう設計されていない。したがって、点FとHにおける反力の大きさと方向は未知である。反力と角度を未知数として扱う代わりに、
図A2.56に示すように、結果反力はY成分とD成分に置き換えられる。
G点における反力は、部材GCの両端にあるピン継手が
G点における反力の方向と作用線を固定しているため、
大きさが未知であるのみである。計算の便宜上、
反力Gは成分$G_V$と$G_D$に置き換えられる。
ランディングギアへの横方向荷重の場合、
S方向の反力はF点で特別に設計されたユニットによって
取り除かれる。
$G_D$で置き換える。着陸装置への側方向荷重の場合、
S方向の反力は特別設計ユニットにより点Fで
受け止められる。


#### SOLUTION



歯車上の支持反力F、H、Gを
初期段階として計算する。未知数は6つ、すなわち
$F_S, F_V, F_D, H_V, HD$ および G である（図A2.56参照）。
空間力系に対して静力学平衡の方程式が6つ利用可能なため、
静力学によって反力を求めることができる。図A2.56を参照すると：-
$$
\begin{align*}
\text{To find } F_S \text{ Ttake } \sum S = 0\\
F_S + 0 = 0, \text{ hence } F_S = 0\\
\end{align*} 
$$

反応$G_V$を求めるには、点F、Hを通るS軸についてモーメントを求める。
$$
\begin{align*}
\sum M_S = 3119 \times 50 - 24 G_V = 0\\
\text{Whence, } G_V =6500 \text{ lb. with sense as assumed.}
\end{align*} 
$$

（図A2.55に示すように、15000ポンドの車輪荷重は
V成分とD成分に分解されている）


$G_V$が既知の場合、反応力Gは$(6500)(31.8/24) = 8610$ lbとなり、同様に成分$G_D = (6500)(21/24) = 5690$ lbとなる。

$F_V$を求めるには、点Hを通るD軸についてモーメントを計算する。


$$
\begin{align*}
\sum M_H(D) = 16 G_V + 14672 \times 8 - 22 F_V = 0 = 16 \times 6500 + 14672 \times 8 - 22 F_V = 0\\
\text{Whence } F_V = 10063 \text{ lb. with sense as assumed.}\\
\text{To find } H_D, \text{take moments about V axis
through F.}\\
\sum M_F(V) = - 6 G_D - 22 H_D + 3119 \times 14 = 0 = - 6 \times 5690 - 22 H_D + 3119 \times 14 = 0\\
\text{Whence, } H_D = 433 \text{ lb.}\\
\text{To find } F_D \text{ take } \sum D = 0\\
\sum D = - F_D + H_D + G_D - 3119 = 0 = - F_D + 433 + 5690 - 3119 = 0\\
\text{Whence, } F_D = 3004 \text{ lb.}\\
\text{To find } H_V \text{ take } \sum V = 0\\
\sum V = - F_V + G_V - H_V + 14672 = 0 = - 10063 + 6500 - H_V + 14672 = 0\\
\text{Whence, } H_V = 11109 \text{ lb.}
\end{align*} 
$$

図A2.57は得られた反応をまとめたものである。
構造全体の平衡状態を確認するため、点Aを通るD軸およびV軸についてモーメントを計算する。

$$
\begin{align*}
\sum M_A(D) = - 10063 \times 14 + 6500 \times 8 + 11109 \times 8 = - 140882 + 52000 + 88882 = 0 \text{ (check)}\\
\sum M_A(V) = 5690 \times 8 - 433 \times 8 - 3004 \times 14 = 45520 - 3464 - 42056 = 0 \text{ (check)}
\end{align*} 
$$


![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-48-0.png)





次の解法ステップでは、
オイルショックユニットにかかる力の計算を行います。
図A2.58はオイルショック-車軸ユニットの自由物体図を示しています。ブレース部材 BI および CG は、
両端のピンによる二つの力部材であり、
したがって点 B および C における未知の反力特性は
大きさのみである。点 E における
オレオストラットと上部クロスメンバー FH の
取り付け部は、オレオストラット軸周りの
ねじりモーメントに抵抗し、D 軸および S 軸周りの
反力を提供するように設計されているが、
D 軸および S 軸周りのモーメント反力はない。
したがって未知数は $BI, CG, E_S, E_V, E_D and T_E$、
合計 6 個である。V、Sの力反作用を発生させるが、D軸およびS軸周りのモーメント反作用は発生しない。したがって未知数は $BI, CG, E_S, E_V, E_D, T_E$ の計6つであり、静的に決定されている。図A2.58では、ねじりモーメントTEを二重矢印のベクトルで表す。ベクトルの方向はモーメント軸を表し、
モーメントの回転方向は右手の法則により決定される。
すなわち、右手の親指が矢印と同じ方向を指し、
丸めた指が回転方向を示す。

抵抗するねじりモーメント $T_E$ を求めるには、
点 E を通る V 軸周りのモーメントを計算する。


$$
\begin{align*}
\sum M_E(V) = - 3119 \times 8 + T_E = 0, \\
\text{ hence } T_E = 24952 in. \text{ lb.}\\
\text{To find CG take moments about S axis through E.}\\
\sum M_E(S) = 3119 \times 50 - (24/31.8) CG \times 3 24 (21/31.8) CG = 0\\
\text{Whence, } CG = 8610 \text{ lb.}\\
\end{align*} 
$$
    
これは、Gにおける反応が8610と判明した際に
以前に得られた値を確認するものである。
したがって、CGのD成分とV成分は等しくなる。

$$
\begin{align*}
CG_D = 8610 (21/31.8) = 5690 \text{ lb.}\\
CG_V = 8610 (24/31.8) = 6500 \text{ lb.}\\
\end{align*} 
$$

ブレースストラットBIの荷重を求めるには、点Eを通るD軸周りのモーメントを求める。
$$
\begin{align*}
\sum M_E(D) = - 14672 \times 8 + 3 (BI) 22/24.6 +
24 (BI) 11/24.6 = 0\\
\text{Whence, } BI = 8775 \text{ lb.}\\
\text{and thus,} \\
BI_V = (8775)(22/24.6) = 7840 \text{ lb.}\\
BI_S = (8775)(11/24.6) = 3920 \text{ lb.}\\
\text{To find } E_S \text{ take } \sum S = 0\\
\sum S = E_S - 3920 = 0, \text{ hence } E_S = 3920\\
\text{To find } E_D \text{ take } \sum D = 0\\
\sum D = 5690 - 3119 - E_D = 0, \text{ hence } E_D = 2571\\
\text{To find } E_V \text{ take } \sum V = 0\\
\sum V = - E_V + 14672 - 7840 + 6500 = 0, \\
\text{ hence } EV = 13332 \text{ lb.}
\end{align*} 
$$

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-48-1.png)



図A2.59は上部部材FHの自由物体を示す。未知数は $F_V, F_D, F_S, H_V \text{ および } H_D$ である。油圧ストラットユニットの解析から得られた荷重または反力も図に記録されている。この自由物体の平衡式は以下の通りである：

$$
\begin{align*}
\sum S = 0 = - 3920 + 3920 + F_S = 0, \text{ or } F_S = 0\\
\sum M_F(D) = 22 H_V - 3920 \times 2 - 7840 \times 20 - 13332 \times 6 = 0
\end{align*} 
$$

したがって、$H_V$ = 11110 lb。このチェック値は
以前に得られたものであり、従って
我々の作業に対する検証となる。

$$
\begin{align*}
\sum M_F(V) = 24952 - 2571 \times 6 - 22 H_D = 0\\
\text{ whence, } H_D = 433 \text{ lb.}\\
\sum V = - F_V + 13332 + 7840 - 11110 = 0\\
\text{whence, } F_V = 10063\\
\sum D =  - F_D + 2571 + 433 = 0\\
\text{whence, } F_D = 3004 \text{ lb.}
\end{align*} 
$$


したがって、オイルストラットと上部部材FHの自由物体として解析を進めることで、
着陸装置全体の平衡方程式を用いてこれらの反力を求める場合と同様の
F点とH点における反力が得られる。

各部材にかかる荷重と反力が全て判明したため、
オレオストラットユニットと上部部材FHの
強度設計を実施可能となった。これにより
軸方向応力、曲げ応力、ねじり応力を
算出できる。

ブレースストラットCGとBIにかかる荷重は
軸方向であり、具体的にはそれぞれ
引張8610ポンド、圧縮8775ポンドである。
したがって設計応力の算出に
追加計算は不要である。

#### TORQUE LINK

オレオストラットは二つの伸縮式チューブで構成され、
二つのチューブ間でねじりモーメントを伝達しつつ
下部シリンダーが上部シリンダー内に上方移動できる
機構が必要である。このトルク伝達を実現する最も一般的な方法は
ダブルカンチレバー式ナットクラッカー構造を用いることである。
図A2.60は、本問題におけるオレオストラットに
このようなトルク伝達機構を適用する方法を示している。

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-49-0.png)


本問題において伝達されるトルクは24952 in.lbである。

図A2.60に示すように、トルクリンクの2つのユニット間の反力 $R_2$（点(2)）は、したがって $24952/9 = 2773$ lbとなる。


リンク基部における点(3)の反力$R_3$は
$= 2773 × 8.5/2.75 = 8560$ lbとなる。
これらの反力が判明したことで、
リンクユニット及び接続部の強度設計が可能となった。


### Example Problem 14


図A2.61に示す着陸装置は、主翼下面に取り付けられ、AB線を中心に前方かつ上方へ格納され、動力装置ナセル構造下部によって提供される空間に収まる主脚の代表例である。油圧式ストラットOEはE点で摺動式取付を有し、
これにより部材ABのE点への垂直荷重伝達が
防止される。ただしE点の取付部は油圧式ストラットと
部材AB間のせん断力及びトルク反力を伝達する。
ブレースストラットGD、FD及びCDは両端でピン支承され、
2つの力部材として扱われる。

図A2.61に示すように、非対称な車輪荷重を伴う
水平着陸状態が想定されている。

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-50-0.png)



#### SOLUTION

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-50-1.png)


歯車は支持構造に点A、B、Cで取り付けられている。まず歯車全体を自由体として扱い、これらの点における反力を計算する。図A2.62は荷重と反力を示す空間図を示す。点A、B、Cにおける反力はそれぞれY成分とD成分に置き換えられている。

反力$C_V$を求めるには、点ABを通るS軸についてモーメントを計算する。

$$
\sum M_{AB} = - (15000 + 10000) 64 + 24 C_V = 0
$$

よって $C_V = 66666$ lb となる。図 A2.62 で仮定した方向で。


C点における反力は、
部材CDが両端で固定されているため、
作用線が線CDに沿わなければならない。
したがって、幾何学的に必然として、
抗力成分とストラットCDの荷重が
生じる。よって、

$$
\begin{align*}
C_D =66666 (24/28) =57142 \text{ lb.}\\
C_D =66666 (36.93/28) =87900 \text{ lb. tension}
\end{align*} 
$$

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-50-2.png)


点(A)を通る直線の傾きを求めるには、
その直線の傾きを計算する時間を取る。

$$
\begin{align*}
\sum M_A(D) = - 60000 \times 9 - 40000 \times 29 - 66666 \times 19 + 38 B_V = 0\\
\text{whence, } B_V = 78070 \text{ lb.}\\
\text{To find } A_V, \text{ take } \sum V = 0\\
\sum V = - 78070 + 60000 + 40000 + 66666 - V_A= 0\\
\text{whence, } A_V = 88596 \text{ lb.}
\end{align*} 
$$

BDを見つけるには、点(A)について
瞬間的な操作を行う。

$$
\begin{align*}
\sum M_A(V) = 57142 \times 19 - 15000 \times 9 - 10000 \times 29 - 38 B_D = 0\\
\text{whence, } B_D = 17386 \text{ lb.}\\
\text{To find } A_D \text{ take } \sum D =0\\
\sum D = - 57142 + 15000 + 10000 + 17386 + A_D =0\\
\text{whence } A_D = 14756 \text{ lb.}
\end{align*} 
$$

結果を確認するには、点Oを通るV軸とD軸について
数分かかる。

$$
\begin{align*}
\sum M_O(V) = 5 \times 10000 + 14756 \times 19 - 17386 \times 19 = 0 \text{ (check)}\\
\sum M_O(D)=20000 \times 10 - 88596 \times 19 + 78070 \times 19 =0 \text{ (check)}
\end{align*} 
$$


##### REACTIONS ON OLEO STRUT OE

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-50-3.png)


図A2.63は油圧支柱OEの自由物体図を示す。車軸中心線上の車輪に加わる荷重は点(O)に伝達されている。したがって点(O)における総垂直荷重は
$60000 + 40000 =100000$ となり、D軸方向の総荷重は
$15000 + 10000 =25000$ となる。これらの力のモーメントは、点(O)を通るV軸およびD軸に対して
$M_O(V) = (15000 - 10000) 10 =50000$ in.lb. および
$M_O(D) =(60000 - 40000) 10 =200000$ in.lb. となる。
これらのモーメントは図A2.63において
二重矢印のベクトルで示されている。モーメントの方向は
右手の親指と指の法則によって決定される。

点Eにおける取付部は、
V軸周りのモーメントまたはオレオストラットへの
ねじりモーメントに抵抗するよう設計されている。また
せん断反力$E_S$および$E_D$を提供できるが、
S軸またはD軸周りの曲げ抵抗は提供しない。


未知数は力 $E_S, E_D, DF, DG$ およびモーメント $T_E$ である。

$T_E$ を求めるには、軸 OE を中心とするモーメントを求める。

$$
\sum M_{OE} = - 50000 + T_E = 0, \text{ whence } T_E = 50000 \text{ in.lb.}
$$

$E_S$を求めるには、点Dを通るD軸についてモーメントを取る。
$$
\sum M_D(D) = 200000 - 28 E_S = 0, \text{ whence } E_S = 7143 \text{ lb.}
$$

To find force $DF_V$ take moments about D
axis through point G.

$$
\begin{align*}
\sum M_G(D) = 200000 - 100000 \times 17 - 66666 \times 17 + 34 DF_V = 0\\
\text{whence, } DF_V = 77451 \text{ lb.}\\
\text{Then } DF_S = 77451 (17/28) = 47023 \text{ lb.}\\
\text{and } DF = 77451 (32.72/28) = 90503 \text{ lb.}\\
\end{align*} 
$$

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-51-0.png)


$$
\begin{align*}
\text{To find } DG_V \text{ take } \sum V = 0\\
\sum V = 100000 - 77451 + 66666 - DG_V = 0, \text{ or } DG_V = 89215\\
\text{Then, } DG_S = 89215 (17/28) = 54164 \text{ lb.}\\
DG = 89215 (32.73/28) = 104190 \text{ lb.}\\
\end{align*} 
$$

$E_D$を求めるには、点Dを通るS軸についてモーメントを求める。

$$
\begin{align*}
\sum M_D(S) = - 25000 \times 35 + 28 E_D = 0,\\
E_D = 32143 \text{ lb.}
\end{align*} 
$$

結果はストラットの静的平衡について検証される。
点(O)を通るD軸周りのモーメントを求める。

$$
\begin{align*}
\sum M_O(D) = 200000 + 54164 \times 36 - 47023 \times 36 - 7143 \times 64 = 200000 + 1949904 - 1692828 - 457150 = 0 \text{ (check)}\\
\sum M_O(S) = 32143 \times 64 - 57142 \times 36 = 0 \text{ (check)}
\end{align*} 
$$



##### REACTIONS ON TOP MEMBER AB

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-51-1.png)


図A2.64は、油圧ストラットの前の反力から求めた既知の作用力を受ける部材ABの自由物体を示す。

未知数は $A_D, B_D, A_V$ および $B_V$ である。$B_V$ を求めるには、Dを軸としAを通るモーメントを計算する。


$$
\begin{align*}
\sum M_A(D) = - 89215 \times 2 - 77451 \times 36 - 38 B_V = 0\\
\text{ whence, } B_V = 78070 \text{ lb.}\\
\text{To find } A_V \text{ take } \sum V = 0\\
\sum V = 89215 + 77451 - 78070 - A_V = 0
\text{whence, } A_V = 88596 \text{ lb.}
\end{align*} 
$$
$B_D$を求めるには、点Aを通るV軸のモーメントを求める。
$$
\begin{align*}
\sum M_V(D) = 50000 + 32143 \times 19 - 38 B_D = 0\\
\text{Whence, } B_D = 17386 \text{ lb.}\\
\text{To find } A_D \text{ take } \sum D  = 0\\
\sum D = 17386 - 32143 + A_D =0, \text{ or } A_D = 14757 \text{ lb.}
\end{align*} 
$$

これらの4つの反応力は、歯車を自由体として扱った際に
当初得られた反応力を検証するものであり、
これにより計算結果の数値的検証が可能となる。

歯車の各部にかかる力が判明したため、
各部品は強度と剛性を考慮して設計できる。
油圧式ストラットには、例題13および図A2.60で
論じたようなねじりリンクが必要となる。
