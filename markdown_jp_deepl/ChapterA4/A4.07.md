## A4.7 Load Factors.


負荷係数とは通常記号(n)で表され、
定常飛行中の航空機にかかる力を乗算する数値係数として定義され、
これにより航空機の加速中に作用する動的力系に相当する静的力系が得られる。図A4.11はこれを示す。




![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-74-1.png)


水平定常飛行時の力。Lは航空機の総揚力（主翼＋尾翼）を表す。
したがってL = Wとなる。ここで航空機がZ軸方向に加速上昇すると仮定する。図A4.12は
加速方向と反対の
下方（負の方向）に作用する追加の慣性力 $wa_z/g$ を示す。図A4.11の非加速状態における航空機総揚力Lには、g方向の静的平衡を得るために負荷係数 $n_z$ を乗じる必要がある。

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-74-2.png)



Thus,

$$
\begin{align*}
n_z L - W \frac{W}{g} a_z = 0\\
\text{Since } L = W\\
\text{Hence } n_z = 1 + a_z / g
\end{align*}
$$

飛行機は当然ながらX軸方向にもg軸方向と同様に加速される。したがって図A4.13において、エンジン推力Tの大きさは航空機の抗力Dよりも大きい。

![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-74-3.png)


飛行機を前方へ加速させる。
X方向の慣性力は、負荷係数nxと
飛行機の重量Wを用いて表すのが便利である。
したがって



$$
n_X W = \frac{W}{g} a_x  (See Fig. A14.13)\\
\sum F_X = 0, \text{ whence } T-D-n_X W = 0\\
\text{Hence } n_X = \frac{T-D}{W}
$$






したがって、航空機にかかる荷重は荷重係数を用いて論じることができる。適用荷重係数または限界荷重係数とは、当該航空機の運用中に発生し得る最大荷重係数である。第A4.2条で論じたこれらの荷重は、航空機構造が顕著な永久変形を伴わずに支えなければならない。

設計荷重係数は、限界荷重係数に安全率を乗じた値に等しく、これらの設計荷重は構造が破断や崩壊、すなわち完全な破損を起こさずに支えられなければならない。
