## A4.6 Forces on Airplane in Flight.

図A4.10は、加速飛行状態における航空機にかかる主な力を概略的に示している。


![](../../images/73-Bruhn-analysis-and-design-of-flight-vehicles.pdf-74-0.png)

T = エンジン推力。

L = 翼総揚力＋胴体揚力。

D = 航空機総抗力。

Ma = 翼空力中心を基準とする翼抗力のモーメント。

W = 航空機重量。
$I_L$ = 飛行経路に垂直な慣性モーメント。

I_D = 飛行経路に平行な慣性モーメント。

I_m = 回転慣性モーメント。

E = 飛行経路に垂直な尾部荷重。

水平定速飛行条件では、慣性力 $I_L, I_D, I_m$ はゼロとなる。
自身の重心軸周りの角加速度を伴わない並進運動を伴う加速飛行条件では、
慣性モーメント $I_m$ はゼロとなるが、$I_L$ と $I_D$ は値を持つ。


### Equations of Equilibrium For Steady Flight.


図A4.10から、次の式が得られる：

$$
\begin{align*}
\sum F_X  = 0, D + W \sin \theta -T \cos \beta = 0\\
\sum F_Z* = 0, L - W \cos \theta +T \sin \beta - E = 0\\
\sum M_Y  = 0, - M_a - La - Db + Tc \cos \beta + Ee = 0
\end{align*}
$$

- \* 文字Zに付いている横棒は意味を持たない。横棒がなくても同じ意味である。

### Equations of Equilibrium in Accelerated Flight.

$$
\begin{align*}
\sum F_X = 0, D + W \sin \theta - T \cos \beta - I_D = 0\\
\sum F_Z = 0, L - W \cos \theta + T \sin \beta - I_L = 0\\
\sum M_Y = 0, - Ma - La - Db + Tc \cos \beta + Ee + I_m = 0
\end{align*}
$$


使用された記号：
- 力 - プラスは上向きで尾部方向。
- モーメント - 時計回りが正。
- 重心からの距離：プラスは上向きで尾部方向。
