チャプター A2

力の系のつり合い、トラス構造

A2.1 はじめに

応力解析技術者や構造設計者は、未知の力や反力、あるいは未知の内応力を求めるために、静的つり合い方程式を常に使用しなければならない。これらは、構造物や機械が単純であれ複雑であれ必要不可欠である。これらの方程式を適用する能力は、多くの問題を解くことによって最もよく養われることは疑いない。本章では、これらの重要な物理法則を構造物の力および応力解析へ適用し始める。学生は、静力学と呼ばれる一般的な大学の工業力学の課程を修了しているものと仮定する。

A2.2 静的つり合い方程式

力を完全に定義するには、その大きさ、方向、および作用点を特定する必要がある。力に関するこれらの事実は、一般に力の特性と呼ばれる。作用点の指定の代わりに、より一般的な用語である作用線または位置が力の特性として使われることもある。

空間に作用する力は、3方向の分力と3軸まわりのモーメント（例えば \(F_x, F_y, F_z\) および \(M_x, M_y, M_z\) ）がわかれば完全に定義される。力の系がつり合っているためには、合力が存在してはならない。したがって、つり合い方程式は、力とモーメントの成分をゼロに等しいと置くことによって得られる。以下に種々の力の系に対する静的つり合い方程式を要約する。

一般空間（非共面）力の系のつり合い方程式

\[ \left. \begin{aligned} \Sigma F_x &= 0 \quad &\Sigma M_1 &= 0 \\ \Sigma F_y &= 0 \quad &\Sigma M_2 &= 0 \\ \Sigma F_z &= 0 \quad &\Sigma M_3 &= 0 \end{aligned} \right\} ---- (2.1) \]

したがって、一般的な空間力の系に対しては、利用可能な静的つり合い方程式が6つ存在する。これらのうち、力のつり合い方程式は3つまでしか使用できない。モーメント軸 1, 2, 3 として、任意の \(x, y, z\) 軸のセットをとる方が都合がよいことが多い。6つの方程式すべてを異なる6本の軸まわりのモーメント方程式にすることも可能である。力のつり合い方程式は互いに直交する3本の軸に対して書かれるが、必ずしも \(x, y, z\) 軸である必要はない。

空間共点力の系のつり合い

共点とは、力の系のすべての力が共通の1点を通ることを意味する。したがって、合力が存在するとしても、それはモーメントではなく力でなければならず、合力がゼロであるという条件を完全に定義するためには3つの方程式のみが必要となる。利用可能なつり合い方程式は以下の通りである。

\[ \left. \begin{aligned} \Sigma F_x &= 0 \quad &\Sigma M_1 &= 0 \\ \Sigma F_y &= 0 \quad \text{または} \quad &\Sigma M_2 &= 0 \\ \Sigma F_z &= 0 \quad &\Sigma M_3 &= 0 \end{aligned} \right\} ---- (2.2) \]

合計で3つを超えない範囲で、力とモーメントの方程式を組み合わせて使用することができる。モーメント方程式については、系内のすべての力がその点を通るため、共点を通る軸を使用することはできない。モーメントの軸は、力のつり合い方程式で使用した方向と同じ方向である必要はないが、もちろん同じであってもよい。

空間平行力の系のつり合い

平行力の系では、すべての力の方向は既知であるが、それぞれの大きさと位置は未知である。したがって、大きさを決定するためには1つの方程式が必要であり、力は1つの平面内に限定されないため、位置を決定するためには2つの方程式が必要となる。一般に、この種の力の系において合力をゼロにするために一般的に用いられる3つの方程式は、1つの力の方程式と2つのモーメント方程式である。例えば、 \(y\) 方向に作用する空間平行力系の場合、つり合い方程式は次のようになる。

\[ \Sigma F_y = 0, \quad \Sigma M_x = 0, \quad \Sigma M_z = 0 ---- (2.3) \]

一般共面力の系のつり合い

このタイプの力の系では、すべての力が同一平面上にあり、このような力の系の合力の大きさ、方向、および位置を決定するには3つの方程式のみが必要となる。力またはモーメントの方程式のいずれでも使用できるが、力の方程式は最大で2つまでしか使用できない。例えば、 \(xy\) 平面内に作用する力の系に対しては、以下のつり合い方程式の組み合わせを使用することができる。

$$ \[\begin{aligned} \Sigma F_x &= 0 \quad &\Sigma F_x &= 0 \quad &\Sigma F_y &= 0 \quad &\Sigma M_{z1} &= 0 \\ \Sigma F_y &= 0 \quad \text{または} \quad &\Sigma M_{z1} &= 0 \quad \text{または} \quad &\Sigma M_{z1} &= 0 \quad \text{または} \quad &\Sigma M_{z2} &= 0 \quad 2.4 \\ \Sigma M_z &= 0 \quad &\Sigma M_{z2} &= 0 \quad &\Sigma M_{z2} &= 0 \quad &\Sigma M_{z3} &= 0 \end{aligned}\]

$$

（下付き文字の1, 2, 3は、 \(z\) 軸またはモーメント中心の異なる位置を表す。）

共面共点力の系のつり合い

すべての力が同一平面上にあり、かつ共通の1点を通るため、このタイプの力の系の合力の大きさおよび方向は未知であるが、共点が合力の作用線上にあるため、位置は既知である。したがって、合力を定義しそれをゼロにするためには、2つのつり合い方程式のみが必要となる。利用可能な組み合わせは、

\[ \left. \begin{aligned} \Sigma F_x &= 0 \\ \Sigma F_y &= 0 \end{aligned} \right\} \quad \text{または} \quad \left. \begin{aligned} \Sigma F_x &= 0 \\ \Sigma M_z &= 0 \end{aligned} \right\} \quad \text{または} \quad \left. \begin{aligned} \Sigma F_y &= 0 \\ \Sigma M_z &= 0 \end{aligned} \right\} \quad \text{または} \quad \left. \begin{aligned} \Sigma M_{z1} &= 0 \\ \Sigma M_{z2} &= 0 \end{aligned} \right\} \quad 2.5 \]

（ \(z\) 軸またはモーメント中心の位置は、共点以外でなければならない。）

共面平行力の系のつり合い

このタイプの力の系におけるすべての力の方向が既知であり、かつ力がすべて同一平面上にあるため、このような力の系の合力の大きさおよび位置を定義するには2つの方程式のみが必要となる。したがって、このタイプの力の系に対して利用可能なつり合い方程式は2つのみであり、すなわち、力とモーメントの方程式、または2つのモーメント方程式である。例えば、 \(y\) 軸に平行で \(xy\) 平面内に位置する力の場合、利用可能なつり合い方程式は次のようになる。

\[ \left. \begin{aligned} \Sigma F_y &= 0 \\ \Sigma M_z &= 0 \end{aligned} \right\} \quad \text{または} \quad \left. \begin{aligned} \Sigma M_{z1} &= 0 \\ \Sigma M_{z2} &= 0 \end{aligned} \right\} ---- 2.6 \]

（モーメント中心1と2は、同一の \(y\) 軸上にあってはならない。）

同一線上力の系のつり合い

同一線上力の系とは、すべての力が同一の線上を作用する系であり、換言すれば、力の方向および位置は既知であるが、その大きさは未知である。したがって、同一線上力の系の合力を定義するためには大きさのみを求める必要がある。したがって、利用可能なつり合い方程式は1つだけであり、すなわち

\[ \Sigma F = 0 \quad \text{または} \quad \Sigma M_1 = 0 ---- 2.7 \]

ここで、モーメント中心1は力の系の作用線上にないものとする。

A2.3 力の方向および作用点の特性を確立するための構造フィッティングユニット

空間における力を完全に定義するには6つの方程式が必要であり、力が1つの平面に限定される場合は3つの方程式が必要である。一般に、構造物は既知の荷重を受け、これらの力は内部の応力分布によって構造物内を伝達され、その後、他の外力（一般に反力と呼ばれる）によって支持され、構造物上の既知の力をつり合い状態に保つ。利用可能な静的つり合い方程式は限られているため、構造技術者は、未知の力の方向または作用点、あるいはその両方を決定するフィッティングユニットの使用に頼ることで、決定すべき未知数の数を減らす。以下の図は、力の方向および作用点の特性を確立するために使用されるフィッティングユニットのタイプ、またはその他の一般的な方法を示している。

ボールアンドソケットフィッティング

棒に作用する \(P\) や \(Q\) のような空間力または共面力について、棒の回転が防止されている場合、そのような力の作用線はボールの中心を通らなければならない。したがって、ボールアンドソケットジョイントを使用することにより、この種のフィッティングを介して構造物に作用する力の方向および作用線を決定または制御することができる。このジョイントは回転抵抗を持たないため、いかなる平面における偶力もこれに作用させることはできない。

シングルピンフィッティング

\(xy\) 平面内に作用する \(P\) や \(Q\) のような力に対して、フィッティングユニットはピン中心を通る \(z\) 軸まわりのモーメントに抵抗できないため、このような力の作用線はピン中心を通らなければならない。したがって、 \(xy\) 平面内に作用する力に対しては、図に示すように、ピンジョイントによって方向および作用線が決定される。シングルピンフィッティングはピン軸に垂直な軸まわりのモーメントに抵抗できるため、平面外の力の方向および作用線は、シングルピンフィッティングユニットによっては決定されない。

棒 AB の両端にシングルピンフィッティングがある場合、 \(xy\) 平面内にあり端部 B に作用する任意の力 \(P\) は、端部フィッティング A と B のピン中心を結ぶ線と一致する方向および作用線を持たなければならない。これは、フィッティングが \(z\) 軸まわりのモーメントに抵抗できないためである。
