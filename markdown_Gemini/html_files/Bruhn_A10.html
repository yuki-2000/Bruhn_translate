CHAPTER A10

不静定構造

特殊な方法 - 柱相似法（THE COLUMN ANALOGY METHOD）

A10.1 概要

柱相似法（Column Analogy*）は、折れ線型またはリング型の構造物の曲げモーメントを決定する際に、エンジニアに広く用いられている方法である。この方法は、構造物の曲げによる変形のみを考慮する。

柱相似法を用いる数値計算手順は、第A9章の弾性中心法（elastic center method）を適用する手順と実質的に同一である。

A10.2 柱相似法の一般的な説明

Fig. A10.1は、柱断面の主軸 \(x\) および \(y\) から距離 \((a)\) および \((b)\) の位置にある圧縮荷重 \(P\) によって載荷された短い柱を示している。

支持基部と柱の下端との間の地盤反力を求めるには、荷重 \(P\) を柱の図心に移動させ、さらに主軸まわりのモーメントを加えるのが便利である。ここで、 \(y-y\) 軸および \(x-x\) 軸から距離 \(x\) および \(y\) の位置にある点における地盤反力強度を \(\sigma\) とすると、次のように書くことができる。

\[ \sigma = \frac{P}{A} + \frac{(Pa)y}{I_x} + \frac{(Pb)x}{I_y} \]

ここで、 \(A\) は柱の断面積であり、 \(Pa\) および \(Pb\) はそれぞれ \(x-x\) 軸および \(y-y\) 軸まわりの荷重 \(P\) によるモーメントである。 \(Pa = M_x\) および \(Pb = M_y\) とおくと、上記の式は以下のように書き換えることができる。

\[ \sigma = \frac{P}{A} + \frac{M_x y}{I_x} + \frac{M_y x}{I_y} \quad ---\quad (1) \]

ここで、中心線の長さと形状が Fig. A10.1 の柱の断面と同一であるフレームを考える。このフレームの各部分の幅は、部材の \(1/EI\) に比例するものとする。Fig. A10.2 はこの仮定されたフレームを示している。さらに、フレームの端部 B は固定されており、剛なブラケットが端部 A に取り付けられ、フレームの弾性中心である点 (O) で終わっていると仮定する。フレームは外荷重 \(w_1, w_2\) などにさらされている。

この片持ち構造は、外荷重系 \(w_1, w_2\) などのもとで曲げ変形を受け、点 (O) は変位する。点 (O) に Fig. A10.2 に示すような偶力と2つの力、すなわち \(M_O, X_O, Y_O\) を作用させることで、点 (O) を元の変形していない位置に戻すことができる。点 (O) は剛ブラケットによってフレーム端部 A に接続されているため、弾性中心 (O) におけるこれら3つの力は点 A を静止させ、換言すれば固定させる。したがって、A および B で固定された Fig. A10.2 のフレームについて、弾性中心に作用するモーメントと2つの力は、静定モーメント \(M_s\) を生じさせる外荷重に抵抗する際、不静定モーメント \(M_i\) を生じさせる。フレーム上の点における最終的な真の曲げモーメント \(M\) は、次式に等しくなる。

\[ M = M_s + M_i \]

Fig. A10.2 から、フレーム上の点 B などについて、不静定曲げモーメント \(M_i\) は以下のように書くことができる。

\[ M_i = M_O + X_O y + Y_O x \quad ---\quad (2) \]

第A9章、Art. A9.3において、 \(M_O, X_O, Y_O\) に対する方程式が導出された。それらは以下の通りである。

\[ M_O = - \frac{\sum \phi_s}{\sum ds/I}, \quad Y_O = - \frac{\sum \phi_s x}{I_y}, \quad X_O = - \frac{\sum \phi_s y}{I_x} \]

用語 \(\sum \phi_s\) は、静定 \(M_s/I\) 曲線の面積を表す（ \(E\) は一定と仮定して省略している）。用語 \(\sum \phi_s\) を「弾性荷重」と呼び、これに新しい記号 \(P\) を与える。用語 \(\sum ds/I\) はフレームの「弾性重量」に等しく、各部材の長さにその幅である \(1/I\) を乗じたものの総和に等しい。このフレーム全体の弾性重量に新しい記号 \(A\) を与える。

\(Y_O\) および \(X_O\) の式において、用語 \(\sum \phi_s x\) および \(\sum \phi_s y\) は、フレームの弾性中心を通る \(y\) 軸および \(x\) 軸まわりの荷重として作用する静定 \(M_s/I\) 曲線のモーメントを表している。したがって、 \(\sum \phi_s x\) に新しい記号 \(M_y\) を、 \(\sum \phi_s y\) に新しい記号 \(M_x\) を与える。これら新しい記号を用いると、式 (2) は以下のように書き換えることができる。

\[ M_i = \frac{P}{A} + \frac{M_x y}{I_x} + \frac{M_y x}{I_y} \quad ---\quad (3) \]

式 (1) と 式 (3) を比較すると、それらが類似していることがわかる。言い換えれば、フレームにおける不静定曲げモーメント \(M_i\) は、柱の地盤反力 \(\sigma\) と相似であり、それゆえ式 (1) を用いるこの方法は「柱相似法」と名付けられている。この一般的な説明を踏まえ、いくつかの例題を解くことで、この方法をより明確に説明することができる。

A10.3 1つつの対称軸を持つフレーム

前述の議論から、以下のように書くことができる。

  1. 相似柱の断面は、与えられたフレームの中心線と同一の形状を持つ面積で構成され、その任意の箇所の厚さは、その部分の \(1/EI\) に等しい。

  2. 相似柱の上部に作用する荷重は \(M_s/EI\) 図に等しい。ここで \(M_s\) は、与えられたフレームから導出された任意の基本静定構造における静定モーメントである。 \(M_s\) がフレームの内面に曲げ圧縮を引き起こす場合、それは正の曲げモーメントであり、柱上の相似荷重 \(P\) は下向きに作用する。

  3. 与えられたフレームの点における不静定曲げモーメント \(M_i\) は、相似柱の同じ点における底面反力圧力に等しい。したがって、フレーム上の任意の点における不静定モーメントは、（式 3より）次のようになる。

\[ M_i = \frac{P}{A} + \frac{M_x y}{I_x} + \frac{M_y x}{I_y} \quad ---\quad (4) \]

  1. 任意の点における最終的な真の曲げモーメント \(M\) は、次のようになる。

\[ M = M_s - M_i \quad ---\quad (5) \]

例題 1.

Fig. A10.3は、点 A および D で固定支持された矩形フレームを示している。点 A、B、C、D における曲げモーメントを柱相似法によって決定する。このフレームと荷重は、第A9章のArt. A9.4の例題1と同一であり、そこでは弾性中心法によって解が求められている。

解答 1.

まず、Fig. A10.3 に示すフレームの中心線の形状を、短い柱の断面として考える（Fig. A10.5を参照）。柱断面の各部分の幅は、部材断面の \(1/EI\) に等しい。 \(E\) は一定であるため、これを1とし、幅は \(1/I\) に等しくなる。

計算の最初のステップは、Fig. A10.5 の柱断面積 (A) と、主軸 \(x\) および \(y\) にまわりの柱断面の慣性モーメントを計算することである。

\[ \text{断面積 } A = \sum \frac{ds}{I} = \frac{30}{3} + \frac{30}{3} + \frac{24}{2} = 32 \]

図心軸の位置および慣性モーメント \(I_x\) および \(I_y\) の計算は、弾性中心法によってこの同じ問題を解いているArt. A9.4およびTable A9.1に示されている完全な計算と同一になる。これらの計算はここでは繰り返さない。結果は以下の通りであった。

\[ I_x = 3188, \quad I_y = 3456 \]

フレームは不静定であるため、次のステップは、与えられたフレームおよび荷重と矛盾しない静定フレーム状態を仮定することである。Fig. A10.4はこの解決のために仮定された状態を示しており、すなわち点 A でピン支持、点 D でローラーピン支持されている。したがって、静定 \(M_s\) 図は Fig. A10.4 に示すようになる。ここで、相似柱の断面に荷重として \(M_s/I\) 図を載荷する（Fig. A10.5を参照）。静定モーメントの符号は、静定状態がフレームの内側に引張を引き起こすため正である。柱相似法において、正の \(M_s/I\) 荷重は柱上部への下向きまたは圧縮荷重であり、したがって負の \(M_s/I\) 値は柱への上向きまたは引張荷重となる。

式 (3) は、 \(M_s/I\) 図を荷重としたときの \(x\) 軸および \(y\) 軸まわりのモーメントである \(M_x\) および \(M_y\) の値を必要とする。式 (3) はまた、 \(M_s/I\) 図の面積に等しい全柱荷重 \(P\) を必要とする。

この問題について、Fig. A10.5 からの \(P\) の値は次のようになる。

\[ P = 22.5 \times 24 / 2 = 270 \]

この三角形荷重の図心は、 \(y\) 軸の左側 2 インチの位置にある。Fig. A10.6は、この合力荷重 \(P\) を持つ柱断面を示している。

次に、式 (3) を用いて、柱の底面圧力に等しい不静定モーメント \(M_i\) を求める。式 (3) は曲げモーメント \(M_x\) および \(M_y\) 、および距離 \(x\) および \(y\) を含んでおり、これらはすべて符号を持たなければならない。符号は以下のように決定される。

  • モーメント \(M_x\) が \(x\) 軸より上の部分の底面に圧縮を生じるとき、 \(M_x\) は正とする。

  • モーメント \(M_y\) が \(y\) 軸より右の部分の底面に圧縮を生じるとき、 \(M_y\) は正とする。

  • \(x\) 軸から上方に測定された距離 \(y\) は正、下方に測定されたものは負とする。

  • \(y\) 軸から右方に測定された距離 \(x\) は正、左方は負とする。

Fig. A10.6 より、

\[ P = 270 \]

\[ M_x = 270 \times 9.375 = 2530 \quad (\text{正、なぜなら底面反力が } x \text{ 軸より上の柱部分で圧縮となるため}) \]

\[ M_y = - (270 \times 2) = -540 \quad (\text{負、なぜなら底面反力が } y \text{ 軸より右の柱部分で引張となるため}) \]

式 (3) への代入。

フレーム点 A.

\[ x = -12", \quad y = -20.625" \]

\[ M_i = \frac{P}{A} + \frac{M_x y}{I_x} + \frac{M_y x}{I_y} \]

\[ M_i = \frac{270}{32} + \frac{2530(-20.625)}{3188} + \frac{(-540)(-12)}{3456} \]

\[ = 8.44 - 16.38 + 1.88 = -6.06 \text{ in.lb.} \]

式 (5) からの真の曲げモーメント、

\[ M = M_s - M_i \]

\[ M_s = 0, \quad \text{Fig. A10.5 を参照} \]

したがって、

\[ M_A = 0 - (-6.06) = 6.06 \text{ in.lb.} \]

フレーム点 B.

\[ x = -12", \quad y = 9.325" \]

\[ M_i = \frac{270}{32} + \frac{2530 \times 9.375}{3188} + \frac{(-540)(-12)}{3456} \]

\[ = 8.44 + 7.44 + 1.88 = 17.77 \]

\[ M_B = M_s - M_i = 0 - (17.77) = -17.77 \text{ in.lb.} \]

フレーム点 C.

\[ x = 12", \quad y = 9.325" \]

\[ M_i = \frac{270}{32} + \frac{2530 \times 9.325}{3188} + \frac{(-540)12}{3456} \]

\[ = 8.44 + 7.44 - 1.88 = 14.0 \]

\[ M_C = M_s - M_i = 0 - (14.0) = -14.0 \text{ in.lb.} \]

フレーム点 D.

\[ x = 12, \quad y = -20.625 \]

\[ M_i = \frac{270}{32} + \frac{2530(-20.625)}{3188} + \frac{(-540)12}{3456} \]

\[ = 8.44 - 16.38 - 1.88 = -9.82 \]

\[ M_D = M_s - M_i = 0 - (-9.82) = 9.82 \text{ in.lb.} \]

Fig. A10.7は最終的な真の曲げモーメント図を示しており、これは当然、Art. A9.4の弾性中心法による解と一致する。学生は、柱相似法における数値計算が、弾性中心法におけるものと実質的に同じであることに注意すべきである。

A10.4 非対称フレームまたはリング

非対称のフレームやリングに柱相似法を適用する場合、 \(M/EI\) 図のモーメントは主軸まわりに取る必要があり、慣性モーメントも主軸に関するものである必要がある。

しかし、第A9章の弾性中心法について説明したように、 \(M_x, M_y, I_x\) および \(I_y\) が構造物の非対称性を考慮して修正されれば、図心軸に関するモーメントおよび断面性能を使用することができる。Art. A9.2において、非対称フレーム断面に対する弾性中心における冗長力は以下のようになることが示された（Art. A9.2の式11、14、15を参照）。

\[ M_O = - \frac{\sum \phi_s}{\sum ds/EI} = \frac{P}{A} \quad (\text{対称フレームの場合と同一}) \]

\[ X_O = \frac{\sum \phi_s y - \sum \phi_s x \left( \frac{I_{xy}}{I_y} \right)}{I_x \left( 1 - \frac{I_{xy}^2}{I_x I_y} \right)} \quad ---\quad (a) \]

\[ Y_O = \frac{\sum \phi_s x - \sum \phi_s y \left( \frac{I_{xy}}{I_x} \right)}{I_y \left( 1 - \frac{I_{xy}^2}{I_x I_y} \right)} \quad ---\quad (b) \]

Art. A10.2で以前に行ったように、

\[ M_y = \sum \phi_s x \quad \text{および} \quad M_x = \sum \phi_s y \]

とおく。さらに、

\[ M_y' = M_y \left( \frac{I_{xy}}{I_y} \right) \quad \text{および} \quad M_x' = M_x \left( \frac{I_{xy}}{I_x} \right) \]

\[ \text{および} \quad k = \left( 1 - \frac{I_{xy}^2}{I_x I_y} \right) \]

とおく。

これらを式 (a) および (b) に代入すると、以下を得る。

\[ X_O = \frac{M_x - M_y'}{k I_x}, \quad Y_O = \frac{M_y - M_x'}{k I_y} \]

式 (2) より、次のようになる。

\[ M_i = M_O + X_O y + Y_O x \]

\(X_O\) および \(Y_O\) の値をこの式に代入すると、柱相似法における不静定モーメント \(M_i\) の式として以下が得られる。

\[ M_i = \frac{P}{A} + \frac{(M_x - M_y')y}{k I_x} + \frac{(M_y - M_x')x}{k I_y} \quad ---\quad (6) \]

真のモーメントは、対称断面の場合と同様に、次のようになる。

\[ M = M_s - M_i \]

したがって、柱相似法による非対称フレームの解法は、式 (3) の代わりに式 (6) が使用される点を除いて、対称断面と同じ手順に従う。

A10.5 例題 - 非対称断面

Fig. A10.12は、点 A および D で固定された載荷された非対称フレームを示している。点 A、B、C、D における真の曲げモーメントを求める。この問題は、第A9章のArt. A9.5の例題1と同一であり、そこでは弾性中心法による解が示されている。

解答

Fig. A10.13は相似柱の断面を示している。柱断面の各部材の長さは Fig. A10.12 と同一であり、各部分の幅は \(1/I\) である。解法の第一ステップは、柱の断面性能を求めることである。

柱断面の総面積 (A) は、次のようになる。

\[ (15/1) + (10/1) + (12/2) = 31 \]

必要となるその他の性能は、 \(I_x, I_y\) および \(I_{xy}\) である。

図心 \(x\) および \(y\) 軸の位置、およびこれらの軸まわりの上記の性能を決定するための計算は、第A9章のArt. A9.5の例題1に示されているものと同一であり、そこではこの同じ問題が弾性中心法によって解かれている。結果は、 \(I_x = 606.51, I_y = 942.96\) 、および \(I_{xy} = 217.74\) であった。軸の位置は Fig. A10.13 に示す通りであった。

解法の次のステップは、静定フレーム状態を選択し、静定 ( \(M_s\) ) 図を決定することである。Fig. A10.14は、図に示すようにフレームが切断されているため、2つの片持ち梁という仮定された静定状態を示している。図はまた、(1)、(2) および (3) とラベル付けされた3つの部分からなる静定曲げモーメント図を示している。モーメント図の各部分の面積をそのフレーム部分の (I) で除したものが、柱上の荷重 \(P\) を与える。

\[ P_1 = -1440 \times 3/2 = -2160 \]

\[ P_2 = -1440 \times 15/1 = -21600 \]

\[ P_3 = -1080 \times 4.5/1 = -4860 \]

\[ \sum P = -28620 \]

これらの荷重はフレーム部材の中心線上に作用し、幾何学的モーメント図形状の図心を通る。これらの図心位置は Fig. A10.14 に太い点で示されており、それらの位置は図心 \(x\) および \(y\) 軸に関して与えられている。荷重 \(P_1, P_2\) および \(P_3\) は、負であるため上向きに作用するものとして Fig. A10.13 の柱上に配置される。

次に、重心軸まわりの荷重 \(P\) のモーメントに等しいモーメント \(M_x\) および \(M_y\) を求める。

\[ M_x = -2160 \times 5.242 + 21600 \times 2.258 + 4860 \times 6.758 = 70290 \]

\[ M_y = 2160 \times 3.032 + 21600 \times 5.032 + 4860 \times 5.032 = 139700 \]

式 (6) を解くためには、用語 \(M_x', M_y'\) および \(k\) が必要である。

\[ M_x' = M_x \left( \frac{I_{xy}}{I_x} \right) = 70290 \times 217.74 / 606.51 = 25234 \]

\[ M_y' = M_y \left( \frac{I_{xy}}{I_y} \right) = 139700 \times 217.74 / 942.96 = 32258 \]

\[ k = \left( 1 - \frac{I_{xy}^2}{I_x I_y} \right) = \left( 1 - \frac{217.74^2}{606.51 \times 942.96} \right) = .9171 \]

式 (6) に値を代入すると、以下を得る。

\[ M_i = \frac{-28620}{31} + \frac{(70290 - 32258)y}{0.9171 \times 606.51} + \frac{(139700 - 25234)x}{0.9171 \times 942.96} \]

これより、

\[ M_i = -923 + 68.37y + 132.36x \quad ---\quad (7) \]

フレーム点 A.

\[ x = -5.032, \quad y = -9.758 \]

\[ M_i = -923 + 68.37(-9.758) + 132.36(-5.032) \]

\[ = -923 - 667.15 - 666.0 = -2256 \]

\[ M_A = M_s - M_i = -1440 - 1080 - (-2256) = -264 \text{ in.lb.} \]

フレーム点 B.

\[ x = -5.032, \quad y = 5.242 \]

\[ M_i = -923 + 68.37 \times 5.242 + 132.36(-5.032) \]

\[ = -923 + 358.39 - 666.0 = -1230.6 \]

\[ M_B = M_s - M_i = -1440 - (-1230.6) = -209.4 \text{ in.lb.} \]

フレーム点 C.

\[ x = 6.968, \quad y = 5.242 \]

\[ M_i = -923 + 68.37 \times 5.242 + 132.36 \times 6.968 = 357.7 \]

\[ M_C = M_s - M_i = 0 - (357.7) = -357.7 \text{ in.lb.} \]

フレーム点 D.

\[ x = 6.968, \quad y = -4.758 \]

\[ M_i = -923 + 68.37(-4.758) + 132.36 \times 6.968 = -326 \]

\[ M_D = M_s - M_i = 0 - (-326) = 326 \text{ in.lb.} \]
