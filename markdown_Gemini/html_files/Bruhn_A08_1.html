A8章

静的不定定構造物

アルフレッド・F・シュミット

A8.00 はじめに

静的不定定（冗長）問題とは、静的釣合い方程式だけでは内部応力分布を決定するのに不十分な問題を指す。解を得るためには、変位間の追加の関係式を記述する必要がある。

「弾性力学」によれば、極めて詳細に分析した場合、すべての構造物は静的不定定となる。しかし、技術者は多くの場合、問題を定定にするための多くの仮定や大まかな近似を行うことができる。さらに、曲げの工学理論（ \(\frac{MY}{I}\) ）や、一定せん断流の経験則（ \(q = T/2A\) ）などの補助的な手段も利用可能である（第A-5章、A-6章、およびA-13章からA-15章を参照）。これらは確かに「静力学」の法則ではないが、技術者は応力分布を得るためにこれらを頻繁に使用するため、これらが使用される問題はしばしば「定定」であると見なされる。

航空機の構造解析においては、効率的な設計の要求に鑑み、必要な精度を犠牲にすることなく定定問題を得ることができない場合が多々ある。弾性力学は、このような場合に解を可能にする十分な数の補助条件の存在を保証する。

本章では、代表的な冗長問題の解法を効果的に行うために、第A-7章の方法の拡張を採用する。特定の構造構成を扱う特別な方法は、後の章で示される。

A8.0 重ね合わせの原理

重ね合わせの一般原理は、同時に作用する一連の荷重または原因の合成効果が、個別に作用した場合の効果の代数和に等しいことを示している。この原理は、いくつかの荷重または原因の合成効果が線形関数として変化するという条件に限定される。したがって、部材材料が比例限度を超えて応力を受ける場合、または部材応力が部材のたわみや変形に依存する場合（例えば、曲げ荷重と軸荷重を同時に受ける部材である柱梁など）には、この原理は適用されない。

A8.1 静的不定定問題

静的不定定問題のいくつかの特徴（およびその解釈）を指摘することができる。これらの特徴は、それぞれ解法の基礎を形成するのに有用である。

A. 構造物には、作用荷重を支持するのに必要な数以上の部材が存在する。安定した構造を残したまま \(n\) 個の部材を取り除く（切断する）ことができる場合、元の構造は「 \(n\) 次不定定」であると言われる。

\[ -\text{系}- \]

\(n\) 次不定定構造物において、 \(n\) 個の部材内の力の大きさは、作用荷重と釣り合う応力を確立しながら、任意に割り当てることができる。したがって、図 A8.1（1次不定定構造物）において、(a)の内部力分布は、部材BDの力 \(X\) のいかなる値に対しても、外荷重と釣り合っている。

実際には、外荷重と釣り合わせるためにシステム(b)のみが必要である（ \(X = 0\) に対応）。システム(c)は外荷重の合力がゼロであることに注意されたい。

B. 静的釣合いを満たすすべての可能な応力（力）分布の中で、唯一の正しい解は、運動学的に可能なひずみ（変位）を生じさせるもの、すなわち構造物の連続性を維持するものである。

したがって、例えば、図 A8.1(d)において静的釣合いを満たす曲げモーメント分布は無限に存在する。なぜなら \(M_0\) は任意の値を取り得るからである。これらのうち、その点での支持条件との構造的連続性を維持するために必要な、右端の梁先端のたわみをゼロにするものは1つだけである。

A8.2 最小仕事の原理

冗長問題の解決に極めて有用な定理は、カスティリアノの定理から得ることができる。まず、3つの支持点を持つ梁（図 A8.2）のような冗長反力の問題を考える。反力の1つは静力学からは得られない。

\[ -\text{系}- \]

外荷重との釣合いを確立しながら、 \(n\) 個の部材荷重が任意に割り当てられた場合、要素の相対運動が生じ、 \(n\) 個の点で連続性が損なわれる。その後、相対運動をゼロにするために、 \(n\) 個の合力ゼロの応力（力）分布を重ね合わせることができる。結果として得られる応力分布が正しいものである。

未知の反力（例えば、一番右端のもの）に記号 \(R_x\) を与えると、残りの反力と曲げモーメントは静力学から決定できる。ひずみエネルギー \(U\) は \(R_x\) の関数、すなわち \(U = f(R_x)\) として書くことができる。次の形は：

\[ \frac{\partial U}{\partial R_x} = \delta_{R_x} \]

これは \(R_x\) による \(R_x\) でのたわみである。しかし、支持は剛体であるため、これもゼロでなければならない。したがって、

\[ \frac{\partial U}{\partial R_x} = 0 \quad \text{------------------------ (1)} \]

式(1)は、固定支持で発生するすべての冗長反力に対して成り立つ。これは関数の最小値の数学的条件に対応するため、式(1)は最小仕事の原理を述べていると言われる。言葉で言えば、「固定された冗長反力に関するひずみエネルギーの変化率はゼロである」となる。

A8.2.1 最小仕事による冗長反力の決定

例題 A

図 A8.2 によって提示された問題を、説明として最後まで実行する。曲げモーメントは以下のように与えられた（ \(x, y, z\) は3つの梁区間の左端から測定）。

\[ M = (500 + R_x) x \quad \left(0 < x < \frac{L}{2}\right) \]

\[ M = \frac{(500 + R_x) L}{2} + (R_x - 500) y \quad \left(0 < y < \frac{L}{2}\right) \]

\[ M = R_x (L - z) \quad (0 < z < L) \]

このとき、

\[ U = \frac{1}{2} \int \frac{M^2 \mathrm{d}x}{EI} = \frac{1}{2EI} \int_0^{\frac{L}{2}} (500 + R_x)^2 x^2 \mathrm{d}x \]

\[ + \frac{1}{2EI} \int_0^{\frac{L}{2}} \left[ \frac{(500 + R_x) L}{2} + (R_x - 500) y \right]^2 \mathrm{d}y \]

\[ + \frac{1}{2EI} \int_0^L R_x^2 (L - z)^2 \mathrm{d}z \]

積分記号下での微分を行うと（p. A7.8 参照）、

\[ \frac{\partial U}{\partial R_x} = \frac{1}{EI} \int_0^{\frac{L}{2}} (500 + R_x) x^2 \mathrm{d}x \]

\[ + \frac{1}{EI} \int_0^{\frac{L}{2}} \left[ \frac{(500 + R_x) L}{2} + (R_x - 500) y \right] \left[ \frac{L}{2} + y \right] \mathrm{d}y \]

\[ + \frac{1}{EI} \int_0^L R_x (L - z)^2 \mathrm{d}z \]

\[ \frac{\partial U}{\partial R_x} = 0 = (500 + R_x) \int_0^{\frac{L}{2}} x^2 \mathrm{d}x \]

\[ + \frac{(500 + R_x) L}{2} \int_0^{\frac{L}{2}} \left( \frac{L}{2} + y \right) \mathrm{d}y \]

\[ + (R_x - 500) \int_0^{\frac{L}{2}} y \left( \frac{L}{2} + y \right) \mathrm{d}y + R_x \int_0^L (L - z)^2 \mathrm{d}z \]

計算の完了により、以下が得られた。

\[ R_x = -\frac{1500}{16} \text{ lbs.} = -93.8 \text{ lbs.} \]

負の符号は、 \(R_x\) が下向きであることを示している。

例題 B

図 A8.2(a) の梁の冗長固定端モーメントを決定せよ。

解法:

冗長端モーメントを左端および右端の梁端に対してそれぞれ \(M_L\) および \(M_R\) と指定し、図のように正の方向とした。2つの梁部分（ \(x\) は左端から、 \(y\) は右端から）のモーメント方程式は以下の通りであった。

\[ M = M_L + \frac{M_R + 2PL - M_L}{3L} x \quad (0 < x < L) \]

\[ M = M_R + \frac{M_L + PL - M_R}{3L} y \quad (0 < y < 2L) \]

このとき、

\[ U = \frac{1}{2EI} \int_0^L \left[ M_L + \frac{M_R + 2PL - M_L}{3L} x \right]^2 \mathrm{d}x \]

\[ + \frac{1}{2EI} \int_0^{2L} \left[ M_R + \frac{M_L + PL - M_R}{3L} y \right]^2 \mathrm{d}y \]

積分記号下での微分を行う（p. A7-8 の注記参照）。

\[ \frac{\partial U}{\partial M_L} = 0 = \int_0^L \left[ M_L + \frac{M_R + 2PL - M_L}{3L} x \right] \left[ 1 - \frac{x}{3L} \right] \mathrm{d}x \]

\[ + \int_0^{2L} \left[ M_R + \frac{M_L + PL - M_R}{3L} y \right] \frac{y}{3L} \mathrm{d}y \]

\[ \frac{\partial U}{\partial M_R} = 0 = \int_0^L \left[ M_L + \frac{M_R + 2PL - M_L}{3L} x \right] \frac{x}{3L} \mathrm{d}x \]

\[ + \int_0^{2L} \left[ M_R + \frac{M_L + PL - M_R}{3L} y \right] \left[ 1 - \frac{y}{3L} \right] \mathrm{d}y \]

\[ 0 = M_L \int_0^L \left( 1 - \frac{x}{3L} \right) \mathrm{d}x \]

\[ + \frac{M_R + 2PL - M_L}{3L} \int_0^L x \left( 1 - \frac{x}{3L} \right) \mathrm{d}x \]

\[ + M_R \int_0^{2L} \frac{y}{3L} \mathrm{d}y + \frac{M_L + PL - M_R}{3L} \int_0^{2L} \frac{y^2}{3L} \mathrm{d}y \]

\[ 0 = M_L \int_0^L \frac{x}{3L} \mathrm{d}x + \frac{M_R + 2PL - M_L}{3L} \int_0^L \frac{x^2}{3L} \mathrm{d}x \]

\[ + M_R \int_0^{2L} \left( 1 - \frac{y}{3L} \right) \mathrm{d}y \]

\[ + \frac{M_L + PL - M_R}{3L} \int_0^{2L} y \left( 1 - \frac{y}{3L} \right) \mathrm{d}y \]

積分を評価し、連立して解くことで、以下が得られた。

\[ M_L = -\frac{4}{9} PL \]

\[ M_R = -\frac{2}{9} PL \]

A8.2.2 最小仕事による冗長応力

最小仕事の原理は、静的不定定構造物内部の冗長部材力を決定する問題に適用することができる。したがって、 \(n\) 次不定定構造物において、冗長部材力に記号 \(X, Y, Z, \dots\) などが割り当てられている場合、構造物の連続性のためにこれらの力が取らなければならない値は、これらの力に関連する変位（不連続性）がゼロになるような値である。したがって、冗長反力に使われたのと同様の議論により、以下のように書くことができる。

\[ \left. \begin{aligned} \frac{\partial U}{\partial X} &= 0 \\ \frac{\partial U}{\partial Y} &= 0 \\ &\ \ \vdots \\ &\text{etc.} \end{aligned} \right\} \quad \text{------------------------ (2)} \]

言葉で言えば、「冗長力に関するひずみエネルギーの変化率はゼロである」となる。

式(2)は、式(1)と同様に、最小仕事の原理を述べたものである。これらは \(n\) 次不定定構造物に対して \(n\) 個の方程式を提供する。これらの方程式を連立して解くことで、問題の所望の解が得られる。

例題 C

図 A8.3(a) の片持ち梁とケーブルのシステムは、1次不定定である。最小仕事の原理を用いて部材荷重を求めよ。

解法:

ケーブルの引張荷重を冗長荷重として扱い、記号 \(X\) （図 A8.3(b)）を与えた。考慮したひずみエネルギーは、部分 AC, CD, BC における曲げエネルギーと、ケーブル AB における引張エネルギーであった。梁部分の軸力によるエネルギーは無視できるものとした。

BC における曲げモーメント（原点は B）は以下の通りであった。

\[ M_{\text{BC}} = \left( 1000 - \frac{30}{58.3} X \right) x \]

AC において（原点は A）：

\[ M_{\text{AC}} = \frac{50}{58.3} X \cdot y \]

CD において：

\[ M_{\text{CD}} = 50,000 \]

したがって、ひずみエネルギーは以下のようになった。

\[ U = \frac{X^2}{2} \left( \frac{L}{AE} \right)_{\text{AB}} + \frac{1}{2EI_{\text{BC}}} \int_0^{50} \left( 1000 - \frac{30}{58.3} X \right)^2 x^2 \mathrm{d}x \]

\[ + \frac{1}{2EI_{\text{AC}}} \int_0^{30} \left( \frac{50}{58.3} X \right)^2 y^2 \mathrm{d}y + \frac{1}{2EI_{\text{CD}}} \int_0^{60} (50,000)^2 \mathrm{d}z \]

CD における荷重は \(X\) に依存せず、したがって問題に関与しないため、CD におけるエネルギーを考慮する必要がないことは明らかである。積分記号下で微分すると、

\[ \frac{\partial U}{\partial X} = \frac{58.3 X}{EA_{\text{AB}}} - \frac{30}{58.3} \frac{\int_0^{50} \left( 1000 - \frac{30}{58.3} X \right) x^2 \mathrm{d}x}{EI_{\text{BC}}} \]

\[ + \left( \frac{50}{58.3} \right)^2 \frac{X}{EI_{\text{AC}}} \int_0^{30} y^2 \mathrm{d}y = 0 \]

\[ \frac{58.3 X}{EA_{\text{AB}}} + \frac{11,032 X}{EI_{\text{BC}}} + \frac{6620 X}{EI_{\text{AC}}} = \frac{21.44 \times 10^6}{EI_{\text{BC}}} \]

ここで、

\[ A_{\text{AB}} = 0.025 \text{ in}^2 \]

\[ I_{\text{BC}} = 8.0 \text{ in}^4 \]

\[ I_{\text{AC}} = 10.0 \text{ in}^4 \]

を代入すると、以下が得られた。

\[ X = 613 \text{ lbs.} \]

したがって、

\[ M_{\text{BC}} = \left[ 1000 - \frac{30}{58.3} (613) \right] x = 685x \]

\[ M_{\text{AC}} = \frac{50}{58.3} \cdot 613 \cdot y = 526y \]

例題 D

半円形のピン支持された一様リングが、図 A8.3(c) に示すように支持され荷重を受けている。最初の近似として、水平方向のフロアタイは軸方向に剛であると仮定する。リング内の曲げモーメント分布を求めよ。

解法:

フロア内の軸荷重を冗長荷重として扱った（フロアは剛と仮定されているため、これは固定支持からの冗長なフロア反力と考えることができる）。荷重は図 A8.3(d) に示されている。

曲げモーメント分布は以下の通りであった。

\[ M = X R \sin \theta - PR (1 - \cos \theta) \quad (0 < \theta < 60^\circ) \]

\[ M = X R \sin \theta - \frac{PR}{2} \quad (60^\circ < \theta < 90^\circ) \]

軸荷重は以下の通りであった。

\[ S = P \cos \theta + X \sin \theta \quad (0 < \theta < 60^\circ) \]

\[ S = X \sin \theta \quad (60^\circ < \theta < 90^\circ) \]

ひずみエネルギー（構造物の半分のみ）は以下の通りであった。*

\[ U = \frac{1}{2EI} \int_0^{60^\circ} \left[ X R \sin \theta - PR (1 - \cos \theta) \right]^2 R \mathrm{d}\theta \]

\[ + \frac{1}{2EI} \int_{60^\circ}^{90^\circ} \left[ X R \sin \theta - \frac{PR}{2} \right]^2 R \mathrm{d}\theta \]

\[ + \frac{1}{2AE} \int_0^{60^\circ} \left[ P \cos \theta + X \sin \theta \right]^2 R \mathrm{d}\theta \]

\[ + \frac{1}{2AE} \int_{60^\circ}^{90^\circ} \left[ X \sin \theta \right]^2 R \mathrm{d}\theta \]

* 剛なフロア内でのひずみエネルギーはゼロ（ \(AE \to \infty\) ）。

積分記号下で微分すると、

\[ \frac{\partial U}{\partial X} = \frac{R^3}{EI} X \int_0^{60^\circ} \sin^2 \theta \mathrm{d}\theta \]

\[ - \frac{R^3 P}{EI} \int_0^{60^\circ} (1 - \cos \theta) \sin \theta \mathrm{d}\theta \]

\[ + \frac{R^3 X}{EI} \int_{60^\circ}^{90^\circ} \sin^2 \theta \mathrm{d}\theta \]

\[ - \frac{R^3 P}{2EI} \int_{60^\circ}^{90^\circ} \sin \theta \mathrm{d}\theta \]

\[ + \frac{PR}{AE} \int_0^{60^\circ} \cos \theta \sin \theta \mathrm{d}\theta \]

\[ + \frac{XR}{AE} \int_0^{60^\circ} \sin^2 \theta \mathrm{d}\theta + \frac{XR}{AE} \int_{60^\circ}^{90^\circ} \sin^2 \theta \mathrm{d}\theta \]

評価すると、

\[ \frac{\partial U}{\partial X} = 0 = \frac{\pi}{4} X \left( \frac{R^3}{EI} + \frac{R}{AE} \right) + \frac{3}{8} P \left( \frac{R}{AE} - \frac{R^3}{EI} \right) \]

したがって、

\[ X = \frac{3P}{2\pi} \left[ \frac{ \frac{R^3}{EI} - \frac{R}{AE} }{ \frac{R^3}{EI} + \frac{R}{AE} } \right] \]

A8.3 仮想ダミー荷重法による冗長問題

最小仕事の原理は冗長問題の解析の基礎となり得るが、Art. A8-2.1 や A8-2.2 のように微積分によって直接適用することはしばしば非実用的である。大半の問題において、仮想ダミー荷重法の技術を用いて行えば、作業は容易になる。

以下の導出は、2次不定定トラス構造物に関するものである。軸力に加えて他の荷重（曲げ、ねじり、せん断）が存在する、より一般的な \(n\) 次不定定構造物への拡張は、後で示される。

図 A8.4(a) の2次不定定トラスを考える。図に示される対角材のような2つの部材を「切断」することにより、静的定定にすることができる。この定定（「切断」）構造物に外荷重を作用させると、静的釣合いを満たすように計算された荷重分布「S」が得られる。このとき、発生したひずみにより、切断部「x」および「y」に不連続性が現れる。

これらの不連続性とそれに続く変位を計算するために、仮想ダミー荷重法を使用することができる（Art. A7-7）。この目的のために、図 A8.4(b) および (c) のように、x および y の切断部に仮想荷重を交互に配置する。ダミー単位荷重方程式から、

\[ \left. \begin{aligned} \delta_{x0} &= \sum \frac{S u_x L}{AE} \\ \delta_{y0} &= \sum \frac{S u_y L}{AE} \end{aligned} \right\} \quad \text{------------------------ (3)} \]

\(u_x\) および \(u_y\) は、図 A8.4b, c に示されるような単位冗長応力分布である。下付き文字 “0” は、これらの相対変位が、「元の」応力分布を持つ定定（「切断」）構造物において発生することを示している。

ここで、図 A8.4(d) のように、x および y の切断部にそれぞれ冗長荷重 \(X\) および \(Y\) を作用させることにより、不連続性を解消することが望まれる。荷重 \(X\) は応力分布 \(X u_x\) を生じさせ、同様に \(Y\) は分布 \(Y u_y\) を生じさせる。冗長荷重 \(X\) による切断部 x での相対変位は、 \(\delta_{xx}\) （「X による x での変位」と読む）で与えられる。

\[ \delta_{xx} = \sum \frac{X u_x \cdot u_x L}{AE} = X \sum \frac{u_x^2 L}{AE} \]

また、切断部 y では以下となる（ \(\delta_{yx}\) は「X による y での変位」と読む）。

\[ \delta_{yx} = \sum \frac{X u_x \cdot u_y L}{AE} = X \sum \frac{u_x u_y L}{AE} \]

同様に、荷重 \(Y\) は、それぞれ以下で与えられる切断部 y および x での変位を引き起こす。

\[ \delta_{yy} = \sum \frac{Y u_y \cdot u_y L}{AE} = Y \sum \frac{u_y^2 L}{AE} \]

および

\[ \delta_{xy} = \sum \frac{Y u_y \cdot u_x L}{AE} = Y \sum \frac{u_y u_x L}{AE} \]

ここで、3つの応力システム \(S\) , \(X \cdot u_x\) , および \(Y \cdot u_y\) の同時作用下における各切断部での純相対変位は、

\[ \delta_{x0} + \delta_{xx} + \delta_{xy} = \sum \frac{S u_x L}{AE} + X \sum \frac{u_x^2 L}{AE} \]

\[ + Y \sum \frac{u_y u_x L}{AE} \]

および

\[ \delta_{y0} + \delta_{yx} + \delta_{yy} = \sum \frac{S u_y L}{AE} + X \sum \frac{u_x u_y L}{AE} \]

\[ + Y \sum \frac{u_y^2 L}{AE} \]

連続性のために、これらの純相対変位はゼロでなければならない。上記の各式をゼロに等しいと置き、整理すると、以下の連立方程式が得られる。

\[ \left. \begin{aligned} &X \sum \frac{u_x^2 L}{AE} + Y \sum \frac{u_x u_y L}{AE} = - \sum \frac{S u_x L}{AE} \\ &X \sum \frac{u_y u_x L}{AE} + Y \sum \frac{u_y^2 L}{AE} = - \sum \frac{S u_y L}{AE} \end{aligned} \right\} \quad \text{------------------------ (4)} \]

式(4)は、2つの未知数 \(X\) と \(Y\) に関する2元連立方程式である。 \(X\) と \(Y\) を解くことで、真の応力分布は以下のように計算できる。

\[ S_{\text{TRUE}} = S + X u_x + Y u_y \quad \text{------------------------ (5)} \]

1次不定定にすぎない構造物の場合、式(4)および(5)は \(Y = 0\) と置くことで適用され、以下が得られる。

\[ X \sum \frac{u_x^2 L}{AE} = - \sum \frac{S u_x L}{AE} \]

または、単に、

\[ X = - \frac{\sum \frac{S u_x L}{AE}}{\sum \frac{u_x^2 L}{AE}} \quad \text{------------------------ (4a)} \]

および、

\[ S_{\text{TRUE}} = S + X u_x \quad \text{------------------------ (5a)} \]

定理の証明

上記の定理を証明するために、仮想仕事の原理と、第A-7章の式(18)であるダミー単位荷重変位方程式が導出された議論（p. A7.10 参照）に戻る。変位は、実際の荷重による歪み（ \(\Delta\) ）を移動する内部仮想荷重（u 荷重）によって行われる仕事、すなわち \(\delta = \sum u \Delta\) に等しいことが示されたことを思い出されたい。内部仮想荷重は、所望の変位の点に作用する単位荷重による荷重である。

ここで、静的不定定構造物に対して、これらの内部仮想荷重（u 荷重）は、ダミー単位荷重が構造物の外点に作用するため、一般に不定定である。しかし、私たちは以下を思い出す。

  1. 「作用荷重」と静的釣合い状態にある任意の応力分布（現時点では、ダミー単位荷重を「作用荷重」と考えている）は、外力合力がゼロの応力分布（p. A8.1）によってのみ、正しい（真の）分布と異なる。
  2. 一連の変位を移動する合力ゼロの応力分布は、仕事をしない。

数学的に表現すると、これらの点は以下のようになる。

\[ 1. \quad u_{\text{TRUE}} = u_{\text{STATIC}} + u_{R=0} \]

ここで \(u_{\text{STATIC}}\) は、外力として作用するダミー単位荷重の下で、単純な「切断」構造物において静力学から得られた u 荷重分布であり、 \(u_{R=0}\) は、真の u 荷重分布を与えるために重ね合わせる必要のある、合力ゼロの冗長応力システムである。

\[ 11. \quad \sum \Delta \cdot u_{R=0} = 0 \]

したがって、外力として作用するダミー単位荷重と静的釣合い状態にある任意の u 荷重の集合は、構造物が不整合状態（「真の」u 荷重の集合で計算されたものなど）を通過するときに、同じ量の仮想仕事を行うことになる。すなわち、

\[ \delta = \sum \Delta \cdot u_{\text{TRUE}} = \]

\[ \sum \Delta \cdot (u_{\text{STATIC}} + u_{R=0}) = \]

\[ \sum \Delta \cdot u_{\text{STATIC}} + \sum \Delta \cdot u_{R=0} = \]

\[ \sum \Delta \cdot u_{\text{STATIC}} \]

\[ \text{Q.E.D.} \]
