A8.5 二重冗長トラス（続き）

例題 3

図 A8.14 は、2000# の荷重を支持する4つの同一平面上にある部材からなる構造を示している。同時力系に対して利用可能な静定方程式は2つだけであるため、部材内の荷重に関して、この構造は2次の静定不整合（冗長）である。

解法：

図 A8.15 は、仮定された静定基本構造を示している。2つの部材 CE と DE が冗長部材として選ばれ、図に示すように点 x および y で切断された。この構造と荷重における部材応力は部材上に記録されている。図 A8.16 および A8.17 は、切断面 x および y に作用する単位（1#）引張荷重による部材応力 \(u_x\) および \(u_y\) を示している。表 A8.3 は式 (4) および (5) の完全な計算結果を示している。冗長部材 CE の荷重を \(X\) 、DE の荷重を \(Y\) と指定した。

\[ X \sum \frac{u_x^2 L}{A} + Y \sum \frac{u_x u_y L}{A} = - \sum \frac{S u_x L}{A} \]

表からの値を代入すると：

\[ 2446 X + 2350 Y = 2,253,000 \]

\[ X \sum \frac{u_x u_y L}{A} + Y \sum \frac{u_y^2 L}{A} = - \sum \frac{S u_y L}{A} \]

代入すると：

\[ 2350 X + 3039 Y = 2,488,000 \]

\(X\) と \(Y\) に対する2つの方程式を解くと、 \(X = 521\#\) 、および \(Y = 416\#\) が得られる。任意の部材における真の荷重は \(S + X u_x + Y u_y\) であり、これにより表の最終列の値が得られた。

A8.6 多重冗長トラス

帰納法により、式 (4) は3次以上の不静定（冗長）トラスへの適用に拡張できる。したがって、3重の冗長性に対しては、

\[ \left. \begin{aligned} X \sum \frac{u_x^2 L}{AE} + Y \sum \frac{u_x u_y L}{AE} + Z \sum \frac{u_x u_z L}{AE} &= - \sum \frac{S u_x L}{AE} \\ X \sum \frac{u_x u_y L}{AE} + Y \sum \frac{u_y^2 L}{AE} + Z \sum \frac{u_y u_z L}{AE} &= - \sum \frac{S u_y L}{AE} \\ X \sum \frac{u_x u_z L}{AE} + Y \sum \frac{u_y u_z L}{AE} + Z \sum \frac{u_z^2 L}{AE} &= - \sum \frac{S u_z L}{AE} \end{aligned} \right\} \quad ---(6) \]

そして、 \(X, Y, Z\) を解いた後、

\[ \text{真の応力} = S + X u_x + Y u_y + Z u_z \quad ---(7) \]

A8.7 軸力以外の荷重を受ける部材を含む不静定構造物

式 (6) は、曲げ、ねじり、およびせん断荷重が発生する問題をカバーするために容易に拡張される。したがって、3次の不静定構造物の場合は、

\[ \left. \begin{aligned} X a_{xx} + Y a_{xy} + Z a_{xz} &= -\delta_{xo} \\ X a_{yx} + Y a_{yy} + Z a_{yz} &= -\delta_{yo} \\ X a_{zx} + Y a_{zy} + Z a_{zz} &= -\delta_{zo} \end{aligned} \right\} \quad ---(8) \]

ここで、

\[ \begin{aligned} a_{xx} &= \sum \frac{u_x^2 L}{AE} + \int \frac{m_x^2 dx}{EI} + \int \frac{t_x^2 dx}{GJ} \\ &\quad + \iint \frac{\bar{q}_x^2 dx dy}{Gt} \\ a_{xy} &= a_{yx} = \sum \frac{u_x u_y L}{AE} + \int \frac{m_x m_y dx}{EI} \\ &\quad + \int \frac{t_x t_y dx}{GJ} + \iint \frac{\bar{q}_x \bar{q}_y dx dy}{Gt} \\ a_{yy} &= \sum \frac{u_y^2 L}{AE} + \int \frac{m_y^2 dx}{EI} + \text{etc.} \end{aligned} \]

および

\[ \begin{aligned} \delta_{xo} &= \sum \frac{S u_x L}{AE} + \int \frac{M m_x dx}{EI} + \int \frac{T t_x dx}{GJ} \\ &\quad + \iint \frac{q \bar{q}_x dx dy}{Gt} \\ \delta_{yo} &= \sum \frac{S u_y L}{AE} + \int \frac{M m_y dx}{EI} + \int \frac{T t_y dx}{GJ} \\ &\quad + \iint \frac{q \bar{q}_y dx dy}{Gt} \end{aligned} \]

等々。

そして、ここで \(S, M, T, q\) は静定構造における実際の荷重である。 \(u_x, m_x, t_x, \bar{q}_x\) は、切断面 x における単位仮想荷重による単位（仮想）荷重である。 \(u_y, m_y, t_y, \bar{q}_y\) は、切断面 y における単位荷重に対するものである。等々。

不静定力（群）は軸力である必要はなく、モーメントやトルクなどであってもよい。 不静定力を解いた後、

\[ \left. \begin{aligned} \text{真の軸力} &= S + X u_x + Y u_y + Z u_z \\ \text{真の曲げモーメント} &= M + X m_x + Y m_y + Z m_z \\ &\quad \vdots \end{aligned} \right\} \quad ---(9) \]

等々。

例題 4

図 A8.18 の対称なシートストリンガーパネルを分析し、ストリンガー間の荷重 P の分配を決定する。最初の近似として、シートパネル内のせん断流は一定であると仮定する。すべてのストリンガーは同じ断面積を有している。

解法：

シートパネル内のせん断流を不静定量として選択した。対称性のため、この問題は1次の不静定にすぎない。図 A8.19 は、不静定せん断流 \(X = 1\) による \(u_x\) および \(\bar{q}_x\) 荷重を示している。静定構造物における実際の荷重は、中央のストリンガーのみの一定荷重 P で構成されていた。解決された方程式は以下の通り（式 (8) 参照）。

\[ X \left( \int \frac{u_x^2 dx}{AE} + \iint \frac{\bar{q}_x^2 dx dy}{Gt} \right) = - \left( \int \frac{S u_x dx}{AE} + \iint \frac{q \bar{q}_x dx dy}{Gt} \right) \]

ここで、

\[ \text{実際の荷重} \quad \begin{cases} S = P = \text{定数、中央ストリンガー内} \\ S = 0 \quad \text{サイドストリンガー内} \\ q = 0 \end{cases} \]

\[ \text{仮想荷重} \quad \begin{cases} u_x = L - x \quad \text{サイドストリンガー内} \\ u_x = 2(x - L) \quad \text{中央ストリンガー内} \\ \bar{q}_x = 1.0 \end{cases} \]

評価すると（二重積分は単にパネル面積の定数倍に減少することに注意）：

\[ X \left( 2 \frac{L^3}{AE} + \frac{2b L}{Gt} \right) = - \left( \frac{-P L^2}{AE} \right) \]

\[ X = \frac{P}{2L} \left( \frac{1}{1 + \frac{b AE}{G t L^2}} \right) \]

したがって、真の応力は以下のようになった。

\[ \begin{aligned} P_{\text{ROOT}} &= P - 2LX = P \frac{1}{1 + \frac{L^2 Gt}{AEb}} \quad \text{中央ストリンガー内} \\ P_{\text{ROOT}} &= LX = \frac{P}{2} \frac{1}{1 + \frac{AEb}{L^2 Gt}} \quad \text{サイドストリンガー内} \end{aligned} \]

例題 5

図 A8.19 の問題は、図に示すように2重に不静定である。曲げモーメント分布を求めよ。両方の部材は等しい断面特性を持っている。

解法：

部材 CBD の点 C における曲げモーメントと、部材 AB の点 B における曲げモーメントが不静定量として選択され、切断時に図 A8.20 のピン接合静定構造が得られた。仮想荷重は図 A8.21 および A8.22 に示す通りであった。

図 A8.22 において、単位不静定荷重は単位偶力の自己平衡セットとして適用されたことに注意されたい。実際のおよび仮想の荷重は以下の通りであった：（仮想荷重を持たない部材部分 BD は省略された。これは計算に入り得ない。）

解かれた方程式は以下の通りであった（式 (8) 参照）。

\[ \begin{aligned} &X \left( \sum \frac{u_x^2 L}{AE} + \int \frac{m_x^2 dx}{EI} \right) + Y \left( \sum \frac{u_x u_y L}{AE} + \int \frac{m_x m_y dx}{EI} \right) \\ &\quad = - \left( \sum \frac{S u_x L}{AE} + \int \frac{M m_x dx}{EI} \right) \\ &X \left( \sum \frac{u_x u_y L}{AE} + \int \frac{m_x m_y dx}{EI} \right) + Y \left( \sum \frac{u_y^2 L}{AE} + \int \frac{m_y^2 dx}{EI} \right) \\ &\quad = - \left( \sum \frac{S u_y L}{AE} + \int \frac{M m_y dx}{EI} \right) \end{aligned} \]

積分の評価と \(L^2\) の乗算の後、これらは次のようになる。

\[ \begin{aligned} &X \left( (1 + 2\sqrt{2}) \frac{L}{AE} + \frac{L^3}{3EI} \right) + Y \left( \frac{L\sqrt{2}}{AE} + \frac{L^3}{6EI} \right) \\ &\quad = -PL \left( \frac{(2 + 4\sqrt{2})L}{AE} - \frac{L^3}{6EI} \right) \\ &X \left( \frac{L\sqrt{2}}{AE} + \frac{L^3}{6EI} \right) + Y \left( \frac{L}{\sqrt{2} AE} + \frac{(1 + \sqrt{2})L^3}{3EI} \right) \\ &\quad = -PL \left( \frac{2L\sqrt{2}}{AE} - \frac{L^3}{3EI} \right) \end{aligned} \]

特定のケースとして、次のように仮定された。

\[ \frac{AE}{L} = 100 \frac{EI}{L^3} \quad \text{これにより以下が得られる} \]

\[ \begin{aligned} .3716 X + .1526 Y &= .09011 PL \\ .1526 X + .8121 Y &= .3616 PL \end{aligned} \]

\[ \begin{cases} X = .0645 PL \\ Y = .456 PL \end{cases} \]

その後は通常通り

\[ \begin{aligned} \text{真の応力} &= S + X u_x + Y u_y \\ \text{真のモーメント} &= M + X m_x + Y m_y \end{aligned} \]

A8.8 初期応力

不静定構造において、組み立て時に、適合の欠如（不適合）のために特定の部材を強制的に配置しなければならない場合、初期応力が発生する。状況によっては、荷重下でより好ましい応力分布を得るために、意図的な不適合（「プレストレス」）が採用される。

図 A8.4(a) において、「x切断」を伴う不静定部材が最初に量 \(\delta_{xi}\) だけオーバーサイズ（長すぎる）であった場合（正のX方向の歪みに対応するオーバーサイズは正の \(\delta_{xi}\) ）、x切断における連続性の修正された条件は次のようになる（式 (4) の直前の方程式と比較）。

\[ \delta_{xo} + \delta_{xi} + \delta_{xx} + \delta_{xy} = 0 \]

同様に、Y不静定部材が長すぎた場合は、

\[ \delta_{yo} + \delta_{yi} + \delta_{yx} + \delta_{yy} = 0 \]

次に、前の表記法を使用すると、不静定力に対する適切な方程式は以下の通りとなる。

\[ \left. \begin{aligned} X \sum \frac{u_x^2 L}{AE} + Y \sum \frac{u_x u_y L}{AE} &= -\sum \frac{S u_x L}{AE} - \delta_{xi} \\ X \sum \frac{u_x u_y L}{AE} + Y \sum \frac{u_y^2 L}{AE} &= -\sum \frac{S u_y L}{AE} - \delta_{yi} \end{aligned} \right\} \quad ---(10) \]

式 (10) の「S荷重」は、作用する外力があるために存在する。これらは問題に応じて、ゼロである場合とそうでない場合がある。

例題 6

例題 3 において、組み立て前に部材 CE が 0.01 インチ短すぎた場合、組み立ておよび荷重適用後の応力分布を求めよ。

解法：

前の問題から得られたデータを、以下とともに式 (10) に代入した。

\[ \begin{aligned} \delta_{xi} &= -.01" \quad (\text{"短すぎる"ため負}) \\ \delta_{yi} &= 0 \end{aligned} \]

これにより以下が得られる

\[ \begin{cases} 2446 X + 2350 Y = 2.253 \times 10^6 + .01E \\ 2350 X + 3039 Y = 2.488 \times 10^6 \end{cases} \]

\(E = 29 \times 10^6\) とすると、不静定力は以下のようになった。

\[ \begin{aligned} X &= 985 \text{ lbs.} \\ Y &= 57 \text{ lbs.} \end{aligned} \]

その後、通常通り、

\[ \text{真の応力} = S + X u_x + Y u_y \]

例題 7

例題 5 の構造において、接合部 B で部材 AB と CBD の間に角度の不整合が発生し、組み立て時に部材 AB の端部を時計回りに \(2.7^\circ\) 回転させなければならなかったと仮定する。外力が作用しない状態で発生するモーメントを求めよ。

解法：

初期の不完全性は以下の通りであった。

\[ \delta_{yi} = -2.7 / 57.3 = -.0471 \text{ ラジアン} \]

符号は、元の不整合が不静定モーメント Y の負の方向であったことに注目して決定された。 前の問題から使用された方程式は以下の通りであった（そこでの方程式には \(L^2 \times EI / L^3 = EI / L\) が掛けられていたことに注意）。

\[ \begin{cases} .3716 X + .1526 Y = 0 \\ .1526 X + .8121 Y = .0471 \frac{EI}{L} \end{cases} \]

これを解くと、

\[ \begin{aligned} X &= -.0258 \frac{EI}{L} \\ Y &= .0630 \frac{EI}{L} \end{aligned} \]

真の初期応力とモーメントは通常通り決定された。

場合によっては、不整合の数が不静定の数を超えるか、または不整合が選択された不静定切断部と一致せず、他の場所で発生することがある。このような場合、仮想仕事の原理を使用して、これらの不整合が不静定切断部自体に与える影響を計算できる。したがって、Dummy-Unit 荷重方程式（第A7章）の「仮想仕事」の導出を参照すると、次のように得られる。

\[ \delta_{xi} = \sum u_x \Delta_i \quad ---(11) \]

ここで、 \(\delta_{xi}\) は、構造物全体の初期不完全性（初期ひずみに等価） \(\Delta_i\) による、X不静定切断部における静定構造物の初期不整合である。 \(u_x\) は、以前と同様に、切断面 x における仮想荷重による単位荷重である。式 (11) および Y, Z などの切断に対する同様の式を式 (10) に挿入することができる。

例題 8

例題 3 および 6 を参照して、部材 BE が .025 インチ長すぎると仮定する。他の部材が適切な長さであり、外力が加えられていない場合の初期応力を求めよ。

解法：

例題 3 と同じ方程式を使用するために、そこで使用されたのと同じ x および y 切断で発生する初期の不完全性が計算された。この場合は BE の初期伸びによるものである。したがって、

\[ \begin{aligned} \delta_{xi} &= \sum u_x \Delta_i = (-1.564)(.025") = -.0391" \\ \delta_{yi} &= \sum u_y \Delta_i = (-1.729)(.025) = -.0432" \end{aligned} \]

次に、式 (10) で以前に計算された係数を使用すると、以下が得られた。

\[ \begin{aligned} 2446 X + 2350 Y &= .0391 E \\ 2350 X + 3039 Y &= .0432 E \end{aligned} \]

\(E = 29 \times 10^6 \text{ psi}\) とすると、

\[ \begin{aligned} X &= 263 \text{ lbs.} \\ Y &= 209 \text{ lbs.} \end{aligned} \]

最終的に、

\[ \text{真の初期応力} = S + X u_x + Y u_y \]

A8.9 熱応力

熱ひずみによって不静定構造物に誘起される応力は、上記で提示された方法の適用によって計算することができる。この問題は、熱ひずみによって引き起こされる静定構造物の切断面における相対運動を計算し、次に不静定部材力を切断面に適用することによって連続性を回復するという観点からアプローチすることができる。

具体的には、図 A8.4(a) のような2重不静定トラスを考える。「x」および「y」の切断を行って構造物を静定にした後、温度分布の適用を想定する。切断面において相対変位が発生し、これを \(\delta_{xT}\) および \(\delta_{yT}\) で表す。

これらの変位は、第 A7 章の A7.8 節に示されているように、Dummy-Unit Load 法によって計算することができる。この計算が完了した後、問題は初期ひずみ（A8.8節）と同様に進む。したがって、切断面における連続条件は次のようになる（式 (4) の直前の方程式と比較し、簡単のために外力が存在せず、 \(\delta_{xo} = \delta_{yo} = 0\) と仮定する）。

\[ \left. \begin{aligned} \delta_{xT} + \delta_{xx} + \delta_{xy} = 0 \\ \delta_{yT} + \delta_{yx} + \delta_{yy} = 0 \end{aligned} \right\} \]

トラスにおいて、熱ひずみは、Dummy-Unit Load 方程式（第 A7 章、A7.7 節および A7.8 節参照）の「仮想仕事」の導出によって与えられる切断面における相対変位を次のように生成する。

\[ \left. \begin{aligned} \delta_{xT} &= \int u_x \alpha T dx \\ \delta_{yT} &= \int u_y \alpha T dx \end{aligned} \right\} \quad ---(12) \]

ここで、 \(\alpha\) は材料の熱膨張係数、 \(T\) は周囲温度からの上昇温度、そして \(u_x\) および \(u_y\) はそれぞれ x および y 切断面における仮想荷重による単位荷重分布である。式 (12) の和は、部材内および部材間での \(\alpha\) および \(T\) の変化の可能性を考慮するために、有限の和ではなく積分として書かれている。そうすると、2重不静定トラスにおける熱応力の最終方程式は次のようになる。

\[ \left. \begin{aligned} X \left\{ \sum \frac{u_x^2 L}{AE} \right\} + Y \left\{ \sum \frac{u_x u_y L}{AE} \right\} &= - \left\{ \int u_x \alpha T dx \right\} \\ X \left\{ \sum \frac{u_x u_y L}{AE} \right\} + Y \left\{ \sum \frac{u_y^2 L}{AE} \right\} &= - \left\{ \int u_y \alpha T dx \right\} \end{aligned} \right\} \quad ---(13) \]

式 (13) は、もちろん、トラス以外の構造物への適用のために拡張することができる。他の荷重に適した表現は、この章の式 (8) 以降、および A7.8 節の他の方程式で以前に開発されている。

例題 10

図 A8.26 の固定梁の上面が均一な温度 T に加熱される。梁の深さ方向に、温度は下面の法線（T = 0）まで線形に変化する。軸方向の拘束および軸力の影響を無視して、発生する端部モーメントを決定せよ。

解法：

この問題は対称性のために1重不静定にすぎず、端部の曲げ拘束をカットすることによって静定にされた。単位偶力（図 A8.26b）の適用により、 \(m = 1 = \text{定数}\) が得られた。そうすると（第 A7 章 A7.8 節の例題 24 参照）、「カット」における熱たわみは次のようになった。

\[ \delta_{xT} = \int_{0}^{L} m d\theta = \int_{0}^{L} 1 \cdot \frac{T \alpha dx}{h} = \frac{T \alpha L}{h} \]

不静定モーメント方程式は（式 13 との類似により）次のようになった。

\[ X \int \frac{m_x^2 dx}{EI} = -\delta_{xT} \]

したがって、

\[ \begin{aligned} X \frac{L}{EI} &= -\frac{T \alpha L}{h} \\ X &= -\frac{T \alpha EI}{h} \end{aligned} \]

不静定モーメントは、予想通り、上部繊維を圧縮する。

例題 11

第 A7 章 A7.8 節の例題 24 で開始された問題、すなわち、内面が外面よりも温度 T だけ均一に加熱されている閉じたリングの熱応力を計算する問題を完了せよ。

解法：

リングは、図 A7.30(b) のように上部でカットすることによって静定にされた。単位荷重と熱たわみは、参照された例題で決定された。以前に行われたたわみ計算の結果は次の通りであった。

\[ \begin{aligned} \delta_{xT} &= \frac{2\pi R \alpha T}{h} \\ \delta_{yT} &= -\frac{2\pi R^2 \alpha T}{h} \\ \delta_{zT} &= 0 \end{aligned} \]

そうすると、式 (13) に対応する方程式は次のように書かれた（式 (8) も参照）。

\[ \begin{aligned} &X \left( \int \frac{u_x^2 ds}{AE} + \int \frac{m_x^2 ds}{EI} \right) + Y \left( \int \frac{u_x u_y ds}{AE} + \int \frac{m_x m_y ds}{EI} \right) \\ &\quad + Z \left( \int \frac{u_x u_z ds}{AE} + \int \frac{m_x m_z ds}{EI} \right) = -\delta_{xT} \\ &X \left( \int \frac{u_x u_y ds}{AE} + \int \frac{m_x m_y ds}{EI} \right) + Y \left( \int \frac{u_y^2 ds}{AE} + \int \frac{m_y^2 ds}{EI} \right) \\ &\quad + Z \left( \int \frac{u_y u_z ds}{AE} + \int \frac{m_y m_z ds}{EI} \right) = -\delta_{yT} \\ &X \left( \int \frac{u_x u_z ds}{AE} + \int \frac{m_x m_z ds}{EI} \right) + Y \left( \int \frac{u_y u_z ds}{AE} + \int \frac{m_y m_z ds}{EI} \right) \\ &\quad + Z \left( \int \frac{u_z^2 ds}{AE} + \int \frac{m_z^2 ds}{EI} \right) = -\delta_{zT} \end{aligned} \]

評価すると、方程式は次のようになった。

\[ \begin{aligned} \frac{1}{EI} X - \frac{R}{EI} Y + 0 \cdot Z &= +\frac{\alpha T}{h} \\ -\frac{R}{EI} X + \frac{1}{2} \left( \frac{1}{AE} + \frac{R^2}{EI} \right) Y + 0 \cdot Z &= -\frac{\alpha R T}{h} \\ 0 \cdot X + 0 \cdot Y + \left( \frac{1}{AE} + \frac{R^2}{EI} \right) Z &= 0 \end{aligned} \]

これらの方程式の最後から、リングの対称性のために当然そうであるべき不静定量 \(Z = 0\) であることに注意されたい。最初の2つの方程式を解くと、

\[ \begin{aligned} X &= \frac{\alpha T EI}{h} \\ Y &= 0 \end{aligned} \]

\(Y\) の非ゼロ値は、対称性のためにあり得ない変化する曲げモーメントを生成することになる。したがって、この結果も合理的である。
